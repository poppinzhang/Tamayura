# 相册渐进显示、同步进度与断点恢复

## 用户表现

Android 与 macOS 共用这套同步逻辑。首次连接、新增共享目录和已有相册更新时，缩略图收到后逐步显示，原来的相册仍可浏览。点击照片仍按需下载原文件；相册同步进度统计元数据和缩略图，不代表原文件已经下载。

断网、来源端停止共享、切到后台停止连接或退出应用时，已写入数据库的缩略图与分页进度保留，已出现的照片和合集仍可离线查看。恢复连接后点击「继续同步」或刷新；重新启动时也会尝试连接已记住的设备，自动发现设备同样会触发恢复。连接中和失败状态显示已保留数量。尚在网络传输中、没有成功写入数据库的单张缩略图需重新请求。

来源端目录没有变化时，从已保存的分页位置和缺失缩略图继续，不重复接收已完成页和已缓存缩略图。来源设备也可以重启：相同设备与相同目录元数据产生相同目录版本。

目录发生增删时，重新核对分页元数据，并复用正式相册和未完成快照中元数据完全匹配的缩略图；同步进度按新目录重新计算。只有完整目录、数量和全部缩略图校验通过后，才更新完成时间并应用删除。未完成同步不会把旧相册条目误删。原文件下载仍使用既有分片断点续传。

## 实现

- gRPC（当前 v4）沿用 v3 起的 `revision`、`knownRevision` 与 `pageToken`，未增加 RPC 或协议兼容分支。来源按媒体 ID 排序，将设备身份、协议版本以及名称、类型、大小、时间、共享目录和相对路径逐项输入 SHA-256，得到跨进程稳定的目录版本；扫描失败仍返回错误，不能当作空目录。
- 媒体库 schema 5 的 `sync_sessions` 持久化下一分页 token 与元数据是否完整，`sync_media` 逐项记录缩略图引用，空引用表示待获取，非空引用也可以对应已完成的空图。图片字节仅存于独立 `thumbnails` 表，元数据复用与提交不复制 BLOB，详见 [缩略图存储](缩略图存储.md)。整页元数据与下一游标在同一个 SQLite 事务中提交，避免进程终止导致漏页；每张缩略图在自己的事务成功后才计入就绪数量。
- `SnapshotCheckpoint` 汇总已收到与已就绪数量。客户端先检查远端版本，再补齐当前页缺失的缩略图，最后从下一 token 拉取后续页。每次最多保留一页元数据与四个缩略图请求；无需将全部缩略图装入 Dart 内存。
- 重新打开数据库时恢复每个设备最新有效暂存会话的可见内容，不再按 24 小时删除断点。SQL 合并正式 `media` 和当前会话已就绪条目，列表、数量、合集、分页和单项查询使用同一集合。成功提交后清理该设备暂存数据；一般网络和来源错误保留断点，无效协议数据则丢弃当前不可继续的会话。
- 恢复任务时事务内轮换会话 ID，通过 SQLite 外键 `ON UPDATE CASCADE` 保留全部缩略图并撤销旧请求的写权限。旧请求迟到、提交或清理不能覆盖新任务；目录版本过期重试也检查原会话所有权。正式提交保留 generation 校验。
- `AppController` 启动时恢复中断计数与「继续同步」入口，身份解析后按真实设备 ID 合并手动连接与 mDNS 请求。250 毫秒合并相册刷新，保留已加载页数；生命周期停止后的旧回调不能恢复过期进度。

## 版本与限制

按 v1.0.0 前的约定，媒体库 schema 升到 5 时清空重建，不迁移旧数据。首次运行新构建需要重新选择共享和接收目录、发现设备并重新建立相册缓存；此后发生的中断可恢复。外部原始媒体和已保存的接收文件不删除，独立下载任务库为 schema 3，媒体库重建不删除该库。两端应更新到本次构建。

本功能不新增后台常驻或自动定时重试。Android 共享仍受系统电源策略影响，Mac 仍需应用运行且系统清醒。源设备重新扫描目录仍需耗时，稳定版本并不省略本地扫描。保留的未完成缩略图会占用应用存储，清除应用数据或卸载会丢失断点；无效协议、目录版本变化或旧版本数据库重建不保证原进度百分比不变。

## 验证

2026-10-10 本轮验证：259 项 Flutter 测试、静态分析与格式检查通过；Android 原生及插件测试 124 项通过（其中 sqflite 的 10 项使用有效缓存），macOS Swift 原生测试 15 项及配置检查通过。尚未进行新功能的真实双机断网恢复验收。

自动化覆盖 SQLite 重开、真实回环 gRPC 断开、单端和双端重启、完成页不重传、页内已完成缩略图复用、源目录增删、空目录、无效分页、扫描失败、并发所有权、旧回调、完整提交后删除、不同设备隔离。控制器覆盖离线重启后的预览与计数、失败后继续、后台停止后恢复、手动连接与自动发现去重、同步中分页及筛选；界面覆盖继续同步入口、计数、小屏和大字体。

真机验收使用 Android 16+ 与 macOS 15+ 的大相册双向同步：在不同页、不同就绪数量断开 Wi-Fi，退出并重启两端，恢复后继续；确认已出现的照片仍保留、计数恢复、已缓存缩略图不重新接收。再在来源增删照片或撤销共享目录权限，确认只有完整成功的快照应用删除。原文件大于 50 MiB 的并发续传单独验收。回环模拟图片测试不能替代实际缩略图解码、SAF 授权和系统睡眠行为验收。
