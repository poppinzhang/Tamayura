# 相册渐进显示、同步进度与断点恢复

## 用户表现

Android、macOS 与 Windows 共用这套同步逻辑。首次连接、新增共享目录和已有相册更新时，缩略图收到后逐步显示，原来的相册仍可浏览。点击照片仍按需下载原文件；相册同步进度统计元数据和缩略图，不代表原文件已经下载。

断网、来源端停止共享、切到后台停止连接或退出应用时，已写入数据库的缩略图与分页进度保留，已出现的照片和合集仍可离线查看。恢复连接后点击仍在显示的失败提示中的「继续同步」，或右上角刷新可立即尝试；启动、返回前台、自动发现和定时触发都遵守最近一次尝试后的间隔，默认 10 分钟，失败也计时。相册与设备页不使用下拉同步，详见 [自动与手动同步](自动与手动同步.md)。连接中和失败状态显示已保留数量。尚在网络传输中、没有成功写入数据库的单张缩略图需重新请求。

每台设备的同步提示从本次连接、接收或整理相册时开始显示，右上角「关闭同步提示」立即隐藏该提示并释放空间，不取消同步。主动关闭后，同次同步后续进度、目录版本重试及最终结果都不再显示；下一次同步重新出现。未主动关闭的提示在成功或失败后保留 5 秒，再用 300 毫秒渐隐并收回卡片及底部间距。设备筛选、合集切换、页面导航不会重置关闭状态或计时，各设备独立处理。重新打开应用时，历史成功或中断状态不主动显示提示卡；已缓存的相册、断点与刷新入口仍保留。

来源端目录没有变化时，从已保存的分页位置和缺失缩略图继续，不重复接收已完成页和已缓存缩略图。来源设备也可以重启：相同设备与相同目录元数据产生相同目录版本。

目录发生增删时，重新核对分页元数据，并复用正式相册和未完成快照中元数据完全匹配的缩略图；同步进度按新目录重新计算。只有完整目录、数量和全部缩略图校验通过后，才应用删除；同步时间在尝试开始时记录，成功提交不会覆盖。未完成同步不会把旧相册条目误删。原文件下载仍使用既有分片断点续传。

## 实现

- gRPC（当前 v4）沿用 v3 起的 `revision`、`knownRevision` 与 `pageToken`，未增加 RPC 或协议兼容分支。来源按媒体 ID 排序，将设备身份、协议版本以及名称、类型、大小、时间、共享目录和相对路径逐项输入 SHA-256，得到跨进程稳定的目录版本；扫描失败仍返回错误，不能当作空目录。
- 媒体库 schema 5 的 `sync_sessions` 持久化下一分页 token 与元数据是否完整，`sync_media` 逐项记录缩略图引用，空引用表示待获取，非空引用也可以对应已完成的空图。图片字节仅存于独立 `thumbnails` 表，元数据复用与提交不复制 BLOB，详见 [缩略图存储](缩略图存储.md)。整页元数据与下一游标在同一个 SQLite 事务中提交，避免进程终止导致漏页；每张缩略图在自己的事务成功后才计入就绪数量。
- `SnapshotCheckpoint` 汇总已收到与已就绪数量。客户端先检查远端版本，再补齐当前页缺失的缩略图，最后从下一 token 拉取后续页。每次最多保留一页元数据与四个缩略图请求；无需将全部缩略图装入 Dart 内存。
- 重新打开数据库时恢复每个设备最新有效暂存会话的可见内容，不再按 24 小时删除断点。SQL 合并正式 `media` 和当前会话已就绪条目，列表、数量、合集、分页和单项查询使用同一集合。成功提交后清理该设备暂存数据；一般网络和来源错误保留断点，无效协议数据则丢弃当前不可继续的会话。
- 恢复任务时事务内轮换会话 ID，通过 SQLite 外键 `ON UPDATE CASCADE` 保留全部缩略图并撤销旧请求的写权限。旧请求迟到、提交或清理不能覆盖新任务；目录版本过期重试也检查原会话所有权。正式提交保留 generation 校验。
- `AppController` 启动时恢复中断计数，身份解析后按真实设备 ID 合并手动连接与 mDNS 请求。250 毫秒合并相册刷新，保留已加载页数；生命周期停止后的旧回调不能恢复过期进度。
- 分页请求等待已经排队的缓存刷新完成，等待期间新增的刷新也先完成，再使用最新游标加载下一页；刷新暂时将分页标记置为不可用时，不丢弃该请求。等待结束后，设备、合集或排序与请求时不匹配，或控制器已关闭时，旧请求失效。分页已开始后仍沿用原有的代次校验，禁止向新筛选追加旧数据。
- 渐进预览的合集聚合和照片分页是独立查询，缩略图可能在两次查询之间写入；新照片与合集入口不保证出现在同一次刷新中。合集选择以实际可见的合集入口为准，控制器测试须等待照片和目标合集均已就绪，再验证选择、失败保留与重试结果。
- `SyncProgress.sessionId` 复用控制器每次连接的所有权对象，仅用于进程内标识本次同步，不写数据库或网络协议。手动地址解析为设备 ID、目录版本重试及最终结果沿用同一标识，新同步使用新标识，避免已关闭提示在身份解析后重新出现。
- `lib/ui/sync_notices.dart` 由首页持有并直接监听模型通知，独立管理每次同步的关闭状态、5 秒计时器与 300 毫秒动画；首次只接纳进行中的同步，重复结束通知不延长计时。`FadeTransition` 与 `SizeTransition` 共用动画收起提示及间距，手动关闭立即移除。筛选仅影响渲染，移除进度、更换模型和销毁页面时释放计时器与动画；此状态不改变实际同步或持久断点。

## 版本与限制

按 v1.0.0 前的约定，媒体库 schema 升到 5 时清空重建，不迁移旧数据。首次运行新构建需要重新选择共享和接收目录、发现设备并重新建立相册缓存；此后发生的中断可恢复。外部原始媒体和已保存的接收文件不删除，独立下载任务库为 schema 3，媒体库重建不删除该库。两端应更新到本次构建。

本功能不新增后台常驻。自动同步到期检查仅在进程运行且允许共享网络时执行；Android 共享仍受系统电源策略影响，桌面仍需应用运行且系统清醒。源设备重新扫描目录仍需耗时，稳定版本并不省略本地扫描。保留的未完成缩略图会占用应用存储，清除应用数据或卸载会丢失断点；无效协议、目录版本变化或旧版本数据库重建不保证原进度百分比不变。
