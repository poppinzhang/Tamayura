# 合集显示模式

## 使用方式

相册合集默认使用紧凑的正方形图片网格。图片之间只留 2 个逻辑像素，隐藏图片下方的文件名、来源、日期及操作区，让同一屏能浏览更多内容。缩略图及已下载的本地图片均居中裁切填满正方形，预览页仍按原比例显示图片。

在「设置 → 相册」开启「详细模式」，恢复带文件名、来源设备、日期或传输操作的卡片布局。开关附带两种模式的说明，默认关闭，在当前设备保存，对所有合集生效，重启后保留。合集封面列表不受此开关影响。

点击图片仍会打开预览，并按已有规则下载尚未保存且未在下载中的原文件。预览显示来源、修改日期、文件大小和媒体类型，点击「详细信息」可查看完整文件名、设备状态、修改时间、类型及非空的合集名、相对路径。元数据来自本地相册缓存，设备离线时也能查看；日期为文件修改时间，不推测照片拍摄时间。

默认网格以小图标提示视频、已保存、离线或下载失败，下载中显示圆形进度。状态图标带提示，图片的无障碍描述保留文件名、来源及状态。分享、打开、失败重试等操作可在预览中完成；移动端长按选择本地文件、桌面端选择删除、排序与分页继续沿用原流程。

## 实现

- `TamayuraModel` 提供 `albumDetailedMode`、`albumDetailedModeSaving` 和 `setAlbumDetailedMode`。`AppController` 使用现有 settings 表的 `albumDetailedMode` 键保存布尔文本，只有值为 `true` 时启用详细模式，无需修改数据库结构。
- 设置仅在成功写入后更新，保存期间禁用开关并显示进度文字。保存失败保留当前模式并提示重试；控制器拒绝并发保存和未完成初始化时的写入，销毁后不更新界面。
- 合集仍使用 `SliverGrid` 懒加载。默认网格按可用宽度除以 96 后四舍五入计算列数，限制为 3–12 列，常见手机宽度显示 4 列；左右边距及行列间距均为 2 个逻辑像素，宽高比为 1，无圆角边框和文字底栏。桌面随可用内容宽度增加列数。
- 详细模式保留原有 2–5 列、左右 18 像素边距、12 像素列间距、14 像素行间距及随文字缩放调整的卡片高度。
- 两种布局共用图片、点击、下载进度及选择逻辑。`AlbumImage` 继续处理本地原图读取、缓存缩略图及读取/解码失败占位；模式切换不会修改媒体记录、排序或下载任务。
- 预览详情面板使用可滚动布局，长文件名与相对路径可以换行；关闭面板返回原预览，不中断下载。布局直接使用现有 Flutter 组件，无新增第三方依赖或外部相册代码。
