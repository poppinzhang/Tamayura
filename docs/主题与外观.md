# 主题与外观

## 设计

参考 [ChatGPT 官方外观说明](https://help.openai.com/en/articles/11958281-updating-your-visual-experience-on-chatgpt)与 [ChatGPT Android 官方应用](https://play.google.com/store/apps/details?id=com.openai.chatgpt)的中性视觉方向：黑白灰承担主要信息层级，减少大面积彩色背景。以下色值为玉响自行设计，并非 ChatGPT 官方设计令牌或逐像素复刻。

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 页面背景 | `#FFFFFF` | `#171717` |
| 卡片背景 | `#F7F7F7` | `#212121` |
| 次级表面 | `#F1F1F1` | `#262626` |
| 选中与强调表面 | `#ECECEC` | `#383838` |
| 主要文字 / 主按钮 | `#171717` | `#F5F5F5` |
| 次要文字 | `#626262` | `#B4B4B4` |
| 细边框 / 分割线 | `#DEDEDE` | `#424242` |

浅色主按钮为黑底白字，深色主按钮为浅色底深色字。错误提示使用各主题下的红色语义令牌。设备在线状态同时由文案、图标表示，不依赖绿色识别。

实际 Flutter 设置页面截图：[浅色](screenshots/theme-light.png)、[深色](screenshots/theme-dark.png)。截图使用测试数据及本机中文字体渲染，不代表 Android 真机系统栏验收。

## 交互与保存

- 入口：「设置 → 外观 → 主题模式」。提供「跟随系统」「浅色」「深色」三选一，默认跟随系统。
- 选择成功后立即更新所有页面，保留当前标签、路由和浏览状态。固定浅色/深色时不受系统模式变化影响；切回跟随系统后恢复自动更新。
- 使用现有 SQLite `settings` 表，键为 `themeMode`，值为 `system`、`light`、`dark`；不新增依赖、表结构或数据迁移。启动时读取，缺失或非法值按跟随系统处理。
- 写入期间禁止重复选择，保存成功后再更新生效模式；失败保留原模式并显示错误，可重新选择重试。主题保存状态独立于媒体刷新，不阻塞下载或目录更新。
- 窄屏或大字体时三选一控件纵向排列，保留完整文字与触摸区域。

## 实现范围

`lib/ui/app_theme.dart` 集中定义两套 `ColorScheme` 与通用控件主题。`TamayuraApp` 监听模型，向 `MaterialApp` 提供 `theme`、`darkTheme` 和 `themeMode`；系统变化由 Flutter 处理。

相册、合集、设备、设置、下载任务、传输状态、关于页和连接弹窗均使用语义颜色。二维码固定黑码白底，避免反色影响识别。照片预览与扫码采用固定中性深色画布以保护照片/相机内容的可读性，照片预览底部操作面板跟随应用主题。

系统状态栏与导航栏图标匹配对应背景；预览与扫码页面单独指定深色画布上的浅色图标。Android `values` / `values-night` 提供白色与炭黑色启动背景。系统原生启动画面跟随系统外观，Flutter 初始化后应用本机保存的主题；手动主题与系统不一致时，启动画面与应用页面可能不同。

## 验证

主题测试覆盖浅深配色、文字与按钮对比度、三种模式切换、运行时系统外观变化、固定模式隔离系统变化、窄屏大字体、路由与设置状态保持。控制器测试覆盖默认值、持久化恢复、非法值、写入失败、重复保存与初始化前调用。

2026-10-10 验证结果：格式检查、`flutter analyze`、174 项 Flutter 测试（含覆盖率）、105 项 Android 原生测试及 Android debug APK 构建均通过。已人工检查两套实际 Flutter 页面截图，并验证 320px 宽度、1.6 倍字号下的纵向切换布局与中文标签无裁切。

Android 16+ 真机上的系统模式切换、冷启动和不同导航方式的系统栏仍需设备验收。
