# 本地媒体删除

## 使用方式

- Android / iOS 界面：在合集内长按已保存的图片或视频，进入多选并选中当前项目；继续点击已保存项目可切换选择，再点击「删除本地文件」。
- 桌面界面：合集内默认显示「删除本地文件」，没有已保存项目时禁用；点击进入多选，选择后点击「确认」。
- 媒体预览：已保存图片和视频的标题栏提供「删除本地文件」按钮。成功后当前页面回到缓存缩略图，显示下载入口；不会自动下载。

多选只允许选择已保存项目。多选期间点击未保存项目不会下载或打开预览，分享和下载重试入口暂时隐藏。取消、返回、切换设备、合集或页面会清空选择；加载更多媒体不会清空已有选择。删除期间禁止重复提交和切换选择，批量操作逐项处理，显示成功与失败数量，保留失败项目的选择供重试。

## 状态与文件处理

`TamayuraModel.deleteLocalFile(MediaView)` 返回是否删除成功。`AppController` 从持久下载记录或已完成任务取得本地 URI，通过 `PlatformBridge.deleteDownload(uri)` 删除本机接收文件，随后按设备及媒体 ID 删除已完成任务和保存记录。不删除对端原文件、相册元数据、缩略图或接收目录；不需要对端在线。

同一媒体复用下载调度锁，禁止删除与重新下载同时执行，有活跃导出任务时拒绝删除。任务清理按媒体身份查询，不依赖最近 100 条完成历史。轮询和分页加载持有本地文件状态修订号，删除前取得的旧快照不能把「已保存」状态重新写回界面。

原生删除失败时保留下载记录和保存标记，并显示错误；批量中某项失败不阻止后续项目。数据库清理失败时保留可重试的保存记录，下次可再次确认文件已不存在并完成清理。文件系统与两个数据库没有跨系统事务，进程在文件已删除、记录尚未清除时退出，可能暂留「已保存」标记，需要再次删除或通过现有文件缺失处理清除。

预览监听保存 URI：URI 被清除时释放已读取的原图、重置预览错误并使在途读取失效，防止删除后迟到的原图再次显示。普通缩略图保留；下一次主动下载成功后重新读取原图。

## 平台实现

- Android：只接受接收文件的 SAF 文档 URI，验证对应目录的持久读写授权，拒绝根目录、子目录及类型不明的文档，调用 `DocumentsContract.deleteDocument`。文档查询明确返回空游标时按已不存在处理；空响应、授权撤销及原因不明的提供者异常保持失败，避免把不可访问误认为已删除。部分提供者对缺失文档抛出异常而非返回空游标时，应用会保留记录并提示重试。
- macOS：复用目录书签与持久授权，支持接收目录移动后解析；在已打开的父目录描述符下查询并删除普通文件，不跟随符号链接。文件或后代目录已不存在视为成功；授权失效和其他 I/O 错误仍失败。
- Windows：复用本地路径校验，固定父目录并按已打开的文件句柄删除；拒绝目录、重解析点，文件缺失视为成功，权限、只读及共享锁错误保持失败。
- Linux（1.0.0 源码）：复用本地路径校验，从 `/` 逐级固定父目录（不跟随符号链接），以 `AT_SYMLINK_NOFOLLOW` 确认目标是普通文件后用不带 `AT_REMOVEDIR` 的 `unlinkat` 删除；父目录或文件已不存在视为成功，目录、符号链接、权限及其他 I/O 错误保持失败。

没有新增数据库迁移、协议字段或远端删除 RPC。iOS 界面遵循上述平台分类，但项目当前没有 iOS 原生存储实现，本功能不新增 iOS 运行支持。
