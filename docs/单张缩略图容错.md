# 单张缩略图容错

macOS 的共享目录扫描与实际缩略图读取之间，文件可能已被删除或大小发生变化。`MediaCatalog.thumbnail` 在目录授权和共享目录生命周期检查内，对单文件缺失、大小变化、无法解码或不支持的媒体返回空字节，使接收端能完成其余目录同步。正常下载仍使用严格的 `withMedia` / `readRange`，不会把缺失或变化文件视为成功。

空缩略图使用现有 gRPC 响应格式，接收端将其记作已完成的缩略图。已失败的同步断点重试后即可继续；源端重新扫描时，已删除文件从目录快照移除，接收端在下一次同步提交时移除对应元数据。

目录授权失败、共享根目录无法打开、无效参数、共享目录被撤销或文件发布记录改变仍会抛出异常。容错后同样校验目录生命周期，避免扫描切换或撤销期间把旧数据提交为有效结果。接收端不吞掉 RPC、断网和目录版本错误。

原生 I/O 错误仅将 `ENOENT` / `ENOTDIR` 归类为文件缺失；权限、磁盘或配额不足、文件描述符耗尽及其他 I/O 故障分别传播错误，不把资源故障缓存为空缩略图。

验证由 `macos/Tests/StorageCoreTests.swift` 覆盖文件删除、大小变化、损坏图像、权限与生命周期错误，以及严格下载语义；`test/mac_thumbnail_sync_test.dart` 通过本地真实 gRPC 验证已有断点恢复、空图缓存和下次扫描的删除同步。
