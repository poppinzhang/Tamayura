# 媒体预览、旋转与切换

本文描述已随 0.9.6 发布的媒体预览功能，发布验证与验收边界见 [0.9.6 发布记录](releases/0.9.6.md)。图片预览沿用本地原图优先、缓存缩略图回退的规则，详见 [相册优先展示本地图片](相册本地原图.md)。

## 旋转与查看角度

图片预览提供顺时针和逆时针旋转按钮，每次旋转 90 度。旋转只改变当前预览的查看角度，不写回原文件、不修改图片元数据，也不改变保存、分享或系统打开时的方向。旋转时重置缩放，以便按新方向适配预览区域；切换到其他媒体后重置旋转与缩放，返回此前图片也从默认查看角度开始。

视频继续显示缓存缩略图，下载完成后通过系统应用播放。预览中不提供视频旋转或内置视频播放。

## 浏览顺序与按需下载

相册打开预览时，保存当前合集和排序对应的完整轻量媒体身份索引。上一项、下一项以该快照为准，可以跨越相册尚未加载的分页；之后的相册刷新、排序或索引位置变化不会把当前预览位置替换成另一媒体。索引不携带整套原图或额外缩略图，按当前访问身份读取所需媒体。

下载页面打开预览时，按当时显示的任务顺序保存媒体序列。之后的任务进度更新和列表重排不会改变此次浏览顺序。单独打开、没有序列的预览仍保留原有查看操作。

从相册打开或在预览中切换到的当前项目没有已保存文件且没有正在排队、下载或保存的任务时，自动发起下载。下载页首次打开任务仍保留原状态，在预览中切换到暂停或失败的任务时重新尝试。已保存文件直接复用，正在运行的任务继续执行，不预下载相邻项目。切换图片、关闭预览或返回相册不会取消已开始的后台下载；暂停、取消和清理仍通过现有下载操作执行。

首尾不循环：第一项不能继续向前，最后一项不能继续向后。界面同时提供上一项、下一项按钮及水平滑动操作，桌面也可使用按钮逐项查看。

## 手势与动效

未放大时，单指向左滑动查看下一项，向右滑动查看上一项。放大后的平移、多指缩放及取消的手势不切换媒体，避免查看图片细节时误翻页；原有纵向拖动关闭预览的操作保留。切换时重置旧项目的拖动、缩放与旋转状态。

成功切换使用 `animations` 的水平 `SharedAxisTransition`，在 280 毫秒内组合定向滑动与淡入淡出；未达到切换条件的短滑使用 180 毫秒回弹。跟手位移即时更新。系统开启减少动画或无障碍导航时，关闭装饰性过渡和回弹动画，保留切换、拖动及关闭操作。

工具按钮固定显示；说明、来源信息和下载操作共用限高的滚动区域。窄屏或大字号下提示可换行、滚动，避免长文案挤占图片画布。

## 数据读取与异常处理

- `lib/ui/media_preview_sequence.dart` 保存预览顺序与身份，`lib/ui/media_preview.dart` 管理当前媒体、手势、旋转、下载触发及动画。
- `TamayuraModel.resolvePreviewMedia(deviceId, mediaId)` 按身份解析当前访问的媒体。生产控制器从仓储读取相册记录，必要时使用保留的下载任务历史；同时恢复该媒体的已保存状态，避免未加载分页中的已下载文件被再次下载。
- 预览读取不改变相册筛选、排序、可见窗口或分页游标，不增加用于累计所有访问媒体的缩略图缓存。
- 索引中的条目已失效、元数据读取失败或无法解析时，保留正在查看的媒体并显示失败提示，可再次执行切换重试。自动下载失败保留现有任务错误与重试操作；建任务前发生的新错误通过提示显示，不把已有的全局错误当作本次下载错误。
- 切换媒体后使旧的本地解码请求失效，迟到的图片或异常结果不会覆盖新项目。关闭预览、控制器关闭及本地删除期间也检查请求是否仍有效；删除完成后，迟到的保存记录读取不能恢复已删除文件的状态。
- 新增按钮及错误提示使用简体中文、日本語和 English 的统一文案资源。本次不修改数据库结构、配置格式或 gRPC 协议，不写入旋转偏好。

## 测试与验收边界

`test/media_preview_navigation_test.dart` 覆盖双向旋转、切换后重置、按钮及滑动边界、只下载当前访问项、已保存及运行中任务复用、失败重试、迟到解码、多指和放大手势、定向滑动与淡化、减少动画、视频入口，以及三种语言下的窄屏大字号布局。

`test/preview_media_lookup_test.dart` 覆盖默认模型查找、跨分页按身份解析、恢复已保存状态且不重复下载、保持相册窗口与缓存边界、下载历史回退、缺失和异常重试，以及本地删除和关闭时的异步竞争。

`test/media_preview_sequence_test.dart` 覆盖完整轻量索引、顺序快照、延迟解析期间快速跳转、过期结果丢弃及解析失败重试。`test/ui_test.dart` 验证相册和下载页两个入口实际传入浏览顺序，合集范围与任务列表重排不影响预览。

`test/media_preview_motion_test.dart` 保留纵向跟手拖动、短滑回弹、回弹中再次操作、取消手势和减少动画下关闭预览的回归。`test/local_image_preview_test.dart`、`test/local_file_deletion_test.dart` 与 `test/album_scroll_data_test.dart` 分别验证预览读取调度、本地删除一致性及相册索引和窗口边界。

上述测试描述自动化覆盖范围，不代表完整发布检查或真机验收已完成。Android、macOS 和 Windows 上的实际横竖图片、触摸和触控板体验、大图内存与解码速度、系统视频播放、来源离线及跨设备下载仍需分别验收；系统权限、后台限制和媒体格式支持沿用现有平台边界。Linux 和 iOS 仍属于项目目标，不能据此声称已经支持运行或发布。
