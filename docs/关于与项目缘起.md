# 关于与项目缘起

## 入口与内容

设置页下方的「关于项目 → 关于」打开独立页面，返回后保留设置页与滚动位置。页面显示：

- 项目名：Tamayura · 玉响。
- 一句话简介：在局域网设备之间浏览与按需传递照片、视频，让美好的瞬间随手可及。
- 实际安装包的版本号与构建号，例如 `0.0.2+3`。
- 项目开源许可 Apache-2.0，以及独立的第三方开源许可入口。
- 「碎碎念」：动画介绍、摄影与项目的缘起、默认端口的生日纪念。

`lib/ui/about_page.dart` 提供关于、项目许可和碎碎念三个页面。内容使用可滚动、最大宽度 720 的布局，适应窄屏和系统大字体。项目简介、故事和项目许可均可离线读取，不依赖媒体数据库或网络服务初始化。

## 版本与许可

`lib/app/app_info.dart` 通过 `package_info_plus` 读取已安装应用的 `version` 和 `buildNumber`，以 `版本+构建号` 显示；不在 UI 中复制 `pubspec.yaml` 的版本值。发布时仍更新 `pubspec.yaml`，或使用 Flutter 的 `--build-name` / `--build-number` 覆盖，关于页随实际安装包变化。缺失或无效的版本信息以及平台异常会显示读取失败提示，可重试，其他内容保持可用。

根目录 `LICENSE` 为 [Apache 官方许可全文](https://www.apache.org/licenses/LICENSE-2.0.txt)，在 `pubspec.yaml` 中声明为 asset。项目许可页展示同一份全文，避免应用内与仓库许可不一致；加载失败提供重试。页面缓存本次 Future，但读取时禁用 AssetBundle 字符串缓存，确保失败后可重新读取。第三方许可使用 Flutter 内置 `LicensePage` 展示依赖自身的许可声明。

## 名字与端口

动画《玉响》（Tamayura / たまゆら）以广岛县竹原市为舞台，以摄影为线索，描绘沢渡楓与朋友们的日常和成长。摄影记录值得珍惜的瞬间，项目希望让这些照片和视频在自己的设备之间流转，更容易被回望和分享。

剧情介绍参考 [动画官方故事简介](https://sh-anime.shochiku.co.jp/tamayura/story.html) 和 [发行方 FlyingDog 简介](https://www.jvcmusic.co.jp/flyingdog/-/Animedata/Z0335.html)。生日采用项目发起者指定的 **1995 年 7 月 28 日**；人物名保留读音 **沢渡（さわたり）楓（ふう）**。取年份末位 `5` 与月日 `0728`，组成 `50728`，作为项目对动画的小小纪念。

`LanEndpoint.defaultPort` 是默认端口唯一来源，控制器启动 gRPC、省略端口的手动 IP 输入、输入框示例及 `tool/smoke_peer.dart` 均使用该值。生产端口已被占用时继续使用原有动态端口策略；mDNS、设备地址展示和二维码始终使用实际监听端口。显式输入端口仍按用户输入连接，不添加旧默认端口兼容逻辑。
