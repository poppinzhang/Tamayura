# 相册优先展示本地图片

## 显示规则

合集内的图片卡片优先读取已下载、保存在本机的图片，来源设备离线也能显示。没有保存记录、文件已不存在、目录授权失效或图片无法解码时，使用数据库中的缓存缩略图；缩略图也不可用时显示占位图。视频继续显示视频缩略图。

本地读取为异步操作，等待期间显示缩略图。下载完成后，卡片自动切换为本机图片；应用内删除本地文件后立即恢复缩略图。图片卡片重新进入视图或应用返回前台时重新读取，处理用户通过其他应用删除文件的情况；不增加文件系统实时监听。

## 实现

- `lib/ui/album_image.dart` 的 `AlbumImage` 监听模型保存 URI 的变化。普通进度更新不重复读取；切换媒体、模型或保存 URI 后，旧请求返回的结果会被丢弃，已销毁的卡片也不会接收迟到结果。
- 复用 `TamayuraModel.loadPreview` 和平台 `readPreview`，从已保存文件生成清晰图像，不依赖来源设备的缩略图。Android 使用 SAF 文档 URI，macOS 使用目录书签授权，Windows 使用本地文件读取；不把所有平台的 URI 当成普通文件路径。
- 相册请求最长边 1024 像素的本地图像，Flutter 解码也限制在 1024 × 1024 内，并保持长宽比；拒绝空字节和超过 8 MiB 的编码结果。点开后的大图保留已有独立的预览尺寸。这样可显示来自原图的细节，同时避免把相册中每张照片按完整像素尺寸同时载入内存。
- 控制器最多同时执行两个原生预览读取，轮到请求及读取完成时重新核对保存 URI、删除状态和控制器生命周期；已离屏销毁或切换图片的卡片使排队请求失效，避免继续解码拖慢当前图片。图片读取失败只回退显示，不在相册刷出全局错误，也不因解码失败清除下载记录；大图预览仍提供重试和外部打开入口。
- 缓存缩略图仍保存在现有数据库中。此次不调整数据库结构、下载流程或网络协议。
