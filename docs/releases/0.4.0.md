## 本版变更

- **Windows x64 实现**：系统目录选择、媒体扫描预览、持久设备身份、DNS-SD 自动发现、SQLite 离线缓存、gRPC 传输、默认应用打开及资源管理器定位；提供构建脚本、原生测试、CI 配置和源码交接入口。已在 Windows 实际构建并通过原生测试；GUI 和真实跨设备验收仍待执行。
- **macOS 后台网络活动**：共享与下载各自持有系统活动声明，避免窗口隐藏、遮挡或最小化时受 App Nap 限速；修复窗口重新可见但未获得焦点时未恢复共享。仍允许系统睡眠，退出后不常驻。
- **Android 共享就绪状态与恢复**：冷启动或系统重建先显示“正在启动”；数据库和配置初始化、目录扫描、广播启动及本机 gRPC 核验成功后才显示“运行中”。失败与超时显示原因、释放资源并保留用户选择，支持返回应用恢复和直接重试。取消、挂起操作、旧会话及迟到扫描不会覆盖新启动结果。
- 相册持久断点、多个共享目录、离线预览、层级接收及超过 50 MiB 的四路并发续传继续保留。

完整变更见 [CHANGELOG](../../CHANGELOG.md)，实现见 [后台共享](../后台共享.md)、[macOS 原型](../macOS原型.md) 和 [Windows 原型](../Windows原型.md)。

## 安装与数据

互联设备应使用相同的 0.4.0。媒体库保持 schema 4，下载任务库保持 schema 2，协议保持 v3，**本次不新增数据库重建**。v1.0.0 前允许覆盖安装，但不承诺旧配置、旧数据或不同版本协议兼容；遇到不兼容时可清理应用数据或卸载重装，再配置目录与设备，不增加历史迁移逻辑。外部原始媒体和已接收文件保留。

Android 同签名 release 可覆盖安装：

```sh
adb install -r dist/0.4.0/Tamayura-0.4.0-android.apk
```

debug 与 release 签名冲突时需先卸载。卸载会清除设置、SAF 授权、离线缓存、下载记录和未完成分片。macOS 完整解压 ZIP 后将 App 放入“应用程序”；未公证包如被系统拦截，在确认来源和校验后通过“隐私与安全性”确认打开，无需关闭全局 Gatekeeper。

Windows ZIP 须完整解压，不单独复制 EXE，并安装相应 Visual C++ x64 运行库；首次连接仅对可信专用网络授权防火墙。

## 已知限制

- Windows 完整 GUI、实际 DNS-SD、防火墙与跨平台传输、Windows 10 1809 及无开发工具的终端用户机仍待验收；构建机自动化通过不代替这些检查。
- Android 后台共享仍受 Doze 和厂商电源策略约束；“运行中”表示本次本机服务初始化通过，不保证网络始终可达。新恢复机制的真机进程回收与锁屏验收未执行。
- macOS 需要进程运行且系统清醒，退出或睡眠会中断共享和传输；Sequoia、Intel 实机以及后台与睡眠恢复仍待验收。
- Windows 当前仅 x64，不提供相机扫码、系统分享面板、后台服务、开机自启、安装器或防睡眠；UNC/网络路径、符号链接、目录联接及 OneDrive 等重解析占位文件不支持。
- 仅可信 IPv4 局域网，无账号、鉴权或 TLS；不提供开机自启和纯局域网远程唤醒。
- 真实双向原文件、大相册断网恢复、授权与系统分享、无开发工具的用户机运行和远端 CI 尚未完成。试用包不代表稳定版或商店发布。
