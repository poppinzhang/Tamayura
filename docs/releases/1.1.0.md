# Tamayura 1.1.0

版本日期：2026-11-15。

当前处于 **v1.1.0 发布准备阶段**：统一版本更新为 **1.1.0+18**（Windows 数字文件版本为 `1.1.0.18`）。本地完整测试、打包、四平台分支 CI、Tag 推送及远端 Release 发布尚未完成；本页先记录发布目标、验证计划、兼容范围与已知限制，实际结果将在发布完成后补充。

## 本版变更

- Windows 共享目录优先恢复已保存索引，启动和返回前台不再无条件全量扫描；运行期间监听文件变化并合并批量事件，仅核对受影响的文件或目录子树，保留手动刷新、首次无缓存、配置变化及通知丢失/溢出时的完整核对兜底。
- Windows 设置新增「共享文件夹完整核对间隔」（1–8760 整数小时，默认 24 小时），上次成功完整核对时间与根配置跨重启保存，局部更新不推迟保底截止时间。
- 修复 Windows 设备发现锁顺序与回调生命周期、原生完成通知批量让出消息循环、普通图片及 RAW 完整帧回退先缩小并物化再应用 EXIF 方向、锁外析构旧索引、下载轮询仅在变化时刷新界面，以及更新辅助进程父进程路径核验与准备错误上报。
- Windows 打包改在中性临时源码副本中执行检查与构建，并在归档前扫描个人目录与原检出路径。
- 沿用 v1.0.0 与 v1.0.1 的媒体库 schema 7、下载任务库 schema 3、本地索引缓存格式 1 和 gRPC v4，不清空或迁移已有用户数据。

完整改动及限制见 `CHANGELOG.md` 的 `1.1.0` 段落；实现细节见 [Windows 本机目录索引](../Windows本机目录索引.md) 和 [Windows 稳定性检查](../Windows稳定性.md)。

## 安装与数据

- 从 v1.0.0 或 v1.0.1 升级沿用媒体库 schema 7、下载任务库 schema 3、现有配置及协议 v4。设置、目录授权、设备记录、离线相册、下载历史与未完成任务继续保留；不清空重建，也不要求卸载正式版。新增「共享文件夹完整核对间隔」与上次完整核对状态保存在现有配置表中，损坏或较新缓存保留原文件并报告错误，详见 [兼容与升级](../兼容与升级.md)。
- Android 沿用现有 release 签名，同签名正式版可覆盖安装。更早不同签名或 debug 包不能作为同签名升级路径；卸载会清除应用数据、目录授权与未完成分片，不能承诺保留这些内容。
- Windows 保留完整发行目录，自动更新要求应用目录及父目录可写；用户数据不因替换应用目录而删除。从 v1.0.0 升级前应先从托盘退出旧进程。目录监听不引入 USN、开机自启或后台系统服务；应用退出、停止共享或睡眠期间的增删可能等待手动刷新或到期完整核对。
- macOS 完整替换 App；未公证包如被系统拦截，在确认来源及校验结果后使用系统“隐私与安全性”的打开方式，不关闭全局 Gatekeeper。Linux 完整解压后运行，移动程序目录后重新运行 `install-desktop-entry.sh`；设置与用户数据保留在原 XDG 目录。
- 更新会中断共享与传输，重新启动后可重试任务。应用内更新可发现正式 Release，Android 仍需系统安装确认，macOS/Linux 通过 Release 页面手动更换程序。

## 已知限制与验收边界

- 尚未完成真实 Windows 大容量 HDD 的启动耗时、磁盘性能与监听表现以及跨设备传输验收，也未完成 Android、macOS、Windows、Linux 之间的真实安装升级、Wi-Fi 发现、目录权限、断网/睡眠恢复、系统菜单、扫码与分享的完整验收。Flutter 回环、原生宿主测试及无头 CI 不能替代这些场景。
- macOS 未公证，Windows 与 Linux 未签名。Android 后台共享受系统电源策略限制；桌面要求应用存活且系统清醒，Linux 无可用托盘时关闭窗口即退出。Linux 发现依赖 Avahi，中日文与媒体预览分别依赖系统字体及解码器。
- Windows/Linux 没有相机扫码或系统分享面板，iOS 尚无运行或发布工程。仅用于可信 IPv4 局域网，无账号、鉴权或 TLS，不跟踪原文件内容修改、不自动下载整本相册、不跨设备去重。
