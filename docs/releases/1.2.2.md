# Tamayura 1.2.2

**1.2.2（1.2.2+21）** 于 2026-11-22（日本时间，UTC 为 `2026-11-21T18:02:49Z`）作为正式版本发布并标记 Latest。Release ID 为 `453878675`，附注 Tag 对象 `441d7a39f6fda9f751e82c2e93d0fddfa22bedd0` 指向提交 `b30e61baf920cc925a4d923f8ba24afad57ff772`。[GitHub Releases](https://github.com/poppinzhang/Tamayura/releases/tag/v1.2.2)

## 本版变更

- 将 Tailscale 远程共享的允许和撤销集中到设置中的「发现远程共享设备」。撤销后，对端再次应答身份探测即可重新授权。相册同步仍在设备页单独管理。
- 简化 Tailscale 设置文案，保留连接状态、共享就绪状态和扫描结果，隐藏本机注册身份。
- 修复 macOS 内嵌节点绕过系统隧道导致的登录或恢复后离线，以及桌面并发请求写入控制管道失败导致的节点退出。

## 安装与数据

- Android 支持 API 36 及以上，同一 release 证书的安装包可覆盖升级。
- macOS 支持 15.0 及以上，退出旧程序后替换完整 App。Windows 支持 Windows 10 1809+ 或 Windows 11 x64，Linux 支持 Ubuntu 24.04 同代 x64 和 arm64。两个平台均应保留解压后的完整目录。
- 媒体库 schema 7、下载任务库 schema 3、gRPC v4 及 Tailscale 绑定格式保持兼容。升级会中断运行中的共享和传输，重启后可继续处理未完成的下载。
