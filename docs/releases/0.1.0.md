## 本版新增与改进

- **后台共享**：「设置 → 后台共享」开启后，来源设备可以锁屏或切换应用，继续提供已选目录的媒体；显示运行通知并提供停止入口。关闭后释放唤醒锁，离开应用时停止共享网络；停止时中止在途目录同步、设备探测及媒体请求，避免大文件或慢对端继续占用资源、阻塞重新开启。设置页显示实际运行状态，并在存在电池优化限制时提供提示和系统设置入口。
- **在线状态判断**：mDNS 设备发现丢失时，先对已记住的地址进行限时 gRPC 身份核验，再更新在线状态；防止旧探测覆盖新连接、IP 复用误连，以及目录授权错误被误判为设备离线。
- **通知与下载**：修复未授予通知权限、关闭应用通知或关闭下载频道时无法下载的问题。发起下载不再请求通知授权；通知关闭时仍可后台接收并在下载任务页查看进度，允许通知时显示系统提醒。新增 Android 16 通知权限与下载调度的原生回归测试，CI 使用 JDK 21。
- **主题与图标**：界面改为中性黑白灰配色，统一相册、设备、设置、下载、关于和弹窗的视觉层级。新增浅色、深色与跟随系统三种主题，立即生效并保存本机选择；保存失败时保留原选择并提示重试。适配窄屏、大字体、系统栏图标和 Android 深色启动背景；二维码保持黑白对比，预览与扫码使用中性深色画布。应用图标采用橙底白字「たまゆら」，适配圆形和圆角桌面，保留原始 PNG 供其它平台复用。
- **关于与许可**：设置新增「关于」，展示实际安装包版本和构建号、项目简介、Apache-2.0 项目许可全文和第三方依赖许可，正文随包分发、可离线阅读。项目新增根目录 `LICENSE`；「碎碎念」介绍动画《玉响》、摄影记录美好瞬间的缘起，以及沢渡楓生日与默认端口的关系。
- **设备身份与名称**：内部身份改由 Android 系统 `ANDROID_ID` 派生；同一系统用户和应用签名下，清除本机数据或同签名重装后，可由仍保留记录的对端识别。界面优先使用系统设备名称，缺失时显示厂商与机型，同名设备按内部身份独立保存。刷新同步更新 gRPC 返回的设备名称；读取身份失败时明确提示并允许刷新重试，不广播随机替代身份。
- **默认连接端口**：统一为 `50728`，纪念沢渡楓的生日 1995 年 7 月 28 日；只输入 IP 时自动采用此端口。端口占用时仍使用并广播实际动态端口，扫码和自动发现以广播信息为准。

多目录共享、保留层级的接收目录、相册合集、离线缩略图、点击下载、大于 50 MiB 四路 gRPC 下载、后台接收与分片续传、图片预览和系统分享继续保留。完整变更见 [CHANGELOG](../../CHANGELOG.md)。实现说明见 [后台共享](../后台共享.md)、[关于与项目缘起](../关于与项目缘起.md)、[应用图标](../应用图标.md) 和 [多目录共享与合集](../多目录共享与合集.md)。

## 安装与升级

**双方设备应安装相同的 0.1.0 版本。** 当前协议为 v3，媒体库 schema 为 3、下载任务库 schema 为 2，与 0.0.2 的结构版本相同。本次未新增迁移逻辑，也不会仅因应用版本号变化就清空同结构数据库；v1.0.0 前不承诺不同应用版本之间的行为或数据兼容。

设备身份从旧随机 UUID 改为 Android 系统标识，不迁移旧 UUID 设备记录。旧记录不兼容时需清理并重新发现；必要时清空应用数据或卸载重装。覆盖安装更早的数据库结构版本时，当前实现可直接清空重建，不提供历史数据迁移。原始共享照片及已保存到外部接收目录的文件会保留。

已安装同签名的 0.0.1 或 0.0.2 release 版，可以覆盖安装：

```sh
adb install -r dist/0.1.0/Tamayura-0.1.0-android.apk
```

首次安装可去掉 `-r`，或将 APK 传到手机后通过文件管理器安装。若装有旧调试版，因 debug 与 release 证书不同，需先卸载。卸载会清除应用设置、SAF 目录授权、已记住的对端、离线缓存、下载记录和未完成分片；外部共享与接收文件保留。

1. 在两台 Android 16+ 手机安装本版，连接同一 Wi-Fi 并打开玉响。
2. 各自添加共享目录，设置接收目录；等待自动发现，或手动输入对端 `IP:端口`、扫描连接二维码。
3. 在来源手机开启「后台共享」，确认设置页显示正在运行。若提示电池限制，打开「电池设置」调整系统策略；长时间锁屏是否可持续访问仍需在实际设备上验证。
4. 来源手机锁屏后，在接收手机刷新相册、查看缩略图和点击媒体下载。接收手机可以切换应用；下载不要求通知权限，允许通知时可显示进度。
5. 不再需要持续共享时，在来源手机关闭开关，或使用运行通知的停止入口。关闭后在应用可见时仍可共享，离开应用后停止共享网络并恢复省电。

## 已知限制与待验收

- 仅支持 Android 16+ 和 IPv4 局域网，尚未提供其它平台安装包、账号、鉴权或 TLS；仅在可信局域网中使用。
- 后台共享仍受 Doze、电池优化和厂商电源策略影响；设置自启动或取消限制不能保证永久运行。未实现开机广播自启，也不能通过纯局域网请求唤起已停止的应用；系统强行停止后需主动打开。真实双机的长时间锁屏、切换 Wi-Fi、通知停止和关闭后省电效果待验收，清单见 [后台共享](../后台共享.md)。
- 恢复出厂设置、更换系统用户或应用签名可能改变设备身份。清除本机数据仍会清除本机设置、目录授权、缓存与已记住的对端；同签名重装、清数据及重新发现的真实双机行为待验收。
- 非实时扫描，只同步媒体增删，不处理文件内容编辑、跨设备内容去重或自动下载整本相册。超大目录的扫描耗时受存储提供者影响。
- 目录关系无法可靠确认时拒绝添加；任一共享目录授权失效或扫描失败会使当次共享快照不可用，需要恢复授权或移除失效目录，对端保留上次完整缓存。
- 未完成分片占用应用存储；外部保存成功后、数据库登记前若进程被强杀，可能留下未登记副本，重试可能另存文件。媒体预览和系统分享仍受 Android 解码器及兼容应用能力限制。
- 真实双机仍需验证多目录授权、嵌套接收成功落盘、同名设备和共享根隔离、权限撤销与恢复、自动发现、扫码、断网恢复、通知关闭时下载及系统分享。

正式公开发布前还需完成上述真机验收及干净环境重建；步骤见 [发布与打包](../发布.md)。
