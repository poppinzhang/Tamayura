# Tamayura 1.2.1

发布日期：2026-11-21（UTC 发布时间 `2026-11-20T18:17:49Z`）。

**1.2.1（1.2.1+20）** 已作为正式版本发布至 [GitHub Releases](https://github.com/poppinzhang/Tamayura/releases/tag/v1.2.1)（Release ID `453034035`，标记 Latest），附注 Tag `v1.2.1`（Tag 对象 `810912a8df17fc0de9e01e806d18cfc5c776ce1a`）明确指向提交 `d96b29c635fc9c72d2bbd5a9df78388a40babc8c`。作为 `v1.2.0` 之后的修复版本，本次修复 Android 上确认 Tailscale 登录后退出、较慢隧道上的远端身份查询，以及节点尚未运行就绪时的误报；并调整 Android 合集页、快速滚动停留时间、Tailscale 设置中的就绪与发现计数，以及中日英界面文案。

## 本版变更

- 修复 Android 上确认「登录 Tailscale」后、打开浏览器前应用退出的问题。内嵌节点使用应用私有目录初始化日志状态，首次登录和恢复已启用的节点共用此修复。
- 远端身份查询允许 40 秒，避免隧道建立较慢时发现不到候选、已确认设备显示离线或下载无法开始；局域网查询仍为 8 秒。发现、在线检查和下载使用同一远端时限。
- 即使已经取得节点身份，也等到节点运行就绪再发现设备、发布共享和发起远程下载，避免刚登录或恢复节点时短暂误报需要登录。
- Android 打开合集后，应用顶栏下直接显示合集名、排序、照片数量和网格。相册介绍、目录设置引导和设备筛选只在合集列表显示。快速滚动块在松手且滚动停止后停留 1.5 秒，再用 300 毫秒淡出。
- Tailscale 设置显示本机远程共享入口是否就绪，以及发现时可见的其他节点数和其中应答 Tamayura 请求的数量。中日英界面与 Android 原生提示文案同步精简。
- 沿用 v1.2.0 的媒体库 schema 7、下载任务库 schema 3 和 gRPC v4，不新增迁移，不清空或迁移已有用户数据。

完整改动及限制见 `CHANGELOG.md` 的 `1.2.1` 段落。

## 安装与数据

- 从 v1.2.0 或其他正式版升级沿用媒体库 schema 7、下载任务库 schema 3、现有配置及协议 v4。设置、目录授权、设备记录、离线相册、下载历史与未完成任务继续保留；不清空重建，也不要求卸载正式版。Tailscale 启用状态与远程共享绑定仍在现有设置表中，无需迁移，详见 [兼容与升级](../兼容与升级.md)。
- 已登录的节点凭据保留在应用私有数据目录下的 `tailscale-node`。本版不要求重新登录，也不会清除设备、离线相册、下载文件与分片。
- Android 沿用现有 release 签名，同签名正式版可覆盖安装。更早不同签名或 debug 包不能作为同签名升级路径；卸载会清除应用数据、目录授权与未完成分片，不能承诺保留这些内容。
- macOS 完整替换 App（含内嵌 helper）；未公证包如被系统拦截，在确认来源及校验结果后使用系统“隐私与安全性”的打开方式，不关闭全局 Gatekeeper。Windows 与 Linux 保留完整发行目录（含 Tailscale helper 与许可证声明），不能只复制主程序；Linux 移动程序目录后重新运行 `install-desktop-entry.sh`，Windows 自动更新要求应用目录及父目录可写。设置与用户数据保留在原目录。
- 更新会中断共享与传输，重新启动后可重试任务。应用内更新可发现正式 Release，Android 仍需系统安装确认，macOS/Linux 通过 Release 页面手动更换程序。

## 已知限制与验收边界

- 本版修复目前只有自动化覆盖。内嵌 Tailscale 节点尚未在真实账号和设备上完成验收：官方登录 / 审批 / 到期、两端逐台授权、Android 确认登录后打开浏览器、较慢隧道上的发现与下载、蜂窝 UIDT 与锁屏、Wi-Fi 切换、桌面睡眠恢复、直连及 DERP 路径、中大文件校验与真实升级仍待验证。
- 已按仅 Wi-Fi / 以太网排队的 Android 下载任务不会在之后补加蜂窝网络，需取消后重新下载；当前没有独立的计费网络自动同步开关。Headscale、系统 VPN、iOS、Flutter Web、UDP、Funnel、exit node、自建控制服务器和直接公网服务均未实现。
- 尚未完成 Android、macOS、Windows、Linux 之间的真实安装升级、Wi-Fi 发现、目录权限、断网/睡眠恢复、系统菜单、扫码与分享的完整验收。Flutter 回环、原生宿主测试及无头 CI 不能替代这些场景。
- macOS 未公证，Windows 与 Linux 未签名。Android 后台共享受系统电源策略限制；桌面要求应用存活且系统清醒，Linux 无可用托盘时关闭窗口即退出。Linux 发现依赖 Avahi，中日文与媒体预览分别依赖系统字体及解码器。
- Windows/Linux 没有相机扫码或系统分享面板，iOS 尚无运行或发布工程。LAN 入口仍仅用于可信 IPv4 局域网，无应用层鉴权或 TLS，禁止公开端口映射；Tailscale 路径提供隧道加密及已批准节点的访问控制，但不保护 LAN 监听。不跟踪原文件内容修改、不自动下载整本相册、不跨设备去重。
