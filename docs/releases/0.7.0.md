## 本版变更

完整版本说明见 [CHANGELOG 0.7.0](../../CHANGELOG.md#070)，GitHub Release 正文使用 Tag 内对应版本段落。

- 修复移动端快速滚动块在日期或字母标记增减时中断拖动、松手后不能隐藏的问题；滑块、当前日期和网格位置在同一帧更新。回归覆盖连续反向拖动、单帧位置与自动隐藏，详见 [合集快速滚动](../合集快速滚动.md)。
- Windows RAW 优先采用可用的内嵌缩略图或预览，缩小并读取像素后再处理方向，减少完整 RAW 和旋转竖图的重复解码；预览不可用时保留完整帧回退。
- Windows 来源端增加最多 32 MiB / 4096 条的内存 LRU 缩略图缓存，合并同一文件的并发生成；缓存命中仍核验文件和共享目录，重扫、撤销共享和失败扫描正确处理失效，权限与 I/O 错误可重试。实现及原生测试范围见 [Windows 缩略图](../Windows缩略图.md)。
- 自动同步默认间隔由 12 小时改为 10 分钟，设置接受 1–525600 的整数分钟。仍按每台设备最近一次尝试计时，失败也计时；手动操作立即尝试，失败设备的 mDNS 上线边沿仍可立即重试一次。设置重置规则见下文及 [自动与手动同步](../自动与手动同步.md)。

## 安装与数据

互联设备应使用同一 **0.7.0** 构建。本次沿用协议 **v4**、媒体库 **schema 7** 和独立下载任务库 **schema 3**，不新增协议或数据库结构变化，也不因本次版本升级主动重建数据库。v1.0.0 前仍不承诺不同应用版本的兼容，不增加迁移或旧协议适配；从更早 schema 安装升级时仍遵循清空重建策略，协议 v4 与 0.5.0 的协议 v3 不互通。

**旧的小时同步间隔不沿用。** 新版只读取 `autoSyncIntervalMinutes`，不读取或转换 `autoSyncIntervalHours`；尚未保存分钟配置时使用默认 **10 分钟**，可在设置中重新选择 **1–525600 分钟**。本次配置变化不需要清空整个数据库。

Android 沿用 0.6.1 的专用 release 签名和当前 Actions Secrets，不重新生成密钥；同签名 release 包可覆盖安装。**从 0.5.0 或更早旧签名安装首次切换时仍须先卸载再安装。** debug 与 release 签名不同，冲突时同样需要卸载。卸载会清除设置、SAF 目录授权、离线缓存、下载记录、任务和未完成分片；签名变化可能改变 `ANDROID_ID`，需重新选择目录并发现设备。**外部共享目录中的原始媒体及已保存接收文件保留。**

macOS 完整解压 ZIP，将 `Tamayura.app` 放入“应用程序”；未公证包被拦截时，确认来源和校验结果后通过系统“隐私与安全性”确认，不关闭全局 Gatekeeper。Windows 完整解压 ZIP 后运行 EXE，保留 SQLite、插件 DLL、Flutter 引擎和 `data`，安装相应 Visual C++ x64 运行库，并只在可信专用网络中允许防火墙访问。

## 已知限制与验收边界

- 当前分发策略为试用性质的 Pre-release；macOS ad-hoc 签名且未公证，Windows 未签名，不是稳定公开发行或应用商店版本。
- 真实设备的快速滚动触感与辅助功能、发现上下线、目录授权、跨平台传输、断网/睡眠恢复、系统菜单、扫码和系统分享尚未完成本版验收。macOS Sequoia / Intel、Windows 10 1809、无开发工具的用户机和 Android 厂商电源策略仍需真实环境验证。
- Windows RAW 预览取决于系统解码器、媒体格式及内嵌预览；缺少预览会回退，无法解码时可显示占位。缓存只在当前进程内有效，32 MiB 上限不包含索引、在途解码器与返回结果副本；单个文件权限、共享冲突或 I/O 错误仍会让同步稍后重试。
- Android 后台共享受系统电源策略约束；桌面共享与下载要求应用运行且系统清醒，不提供后台系统服务、开机自启或远程唤醒。
- 2 MiB 读取块仍需真机测量吞吐与内存表现；单路约低于 70 KiB/s 时可能触发 30 秒停滞重连，连续 30 分钟无数据后失败。分片和接收文件仍可能占用约两倍空间，容量预检不预留空间，部分 Android 文档提供者无法查询容量；保存与数据库登记不是跨系统事务。
- Windows 仅支持 x64，不提供相机扫码、系统分享面板或安装器。当前仅用于可信 IPv4 局域网，无账号、鉴权或 TLS。
