## 本版新增与改进

- **同步过程逐步可见**：首次同步、新增共享相册和增量同步期间，缩略图就绪后显示对应照片与合集，不必等待整个媒体目录同步完毕。可以边同步边浏览、下载。
- **同步进度与重试**：按设备展示连接、接收、提交、完成和中断状态，以及已就绪数量和进度条；失败后可以重试。进度包含已经缓存且本次可复用的缩略图。
- **保留浏览状态与完整缓存**：合并同步期间的界面刷新，保留已加载内容，不打断正在加载的下一页。完整同步成功后才应用删除；中断时撤销本次临时预览，保留上一次完整离线相册。
- **混合目录扫描修复**：Android 扫描先识别文件类型，再校验媒体名称、路径与大小；直接跳过非图片、非视频文件，避免无效非媒体条目中断整次同步。实际媒体错误与目录权限问题仍会提示处理。

本次未改变缩略图生成并发、通信协议或数据库结构。后台共享、相册合集、层级接收与下载等已有功能继续保留。完整变更见 [CHANGELOG](../../CHANGELOG.md)，实现说明见 [同步进度](../同步进度.md)。

## 安装与升级

**双方设备应安装相同的 0.2.0 版本。** 当前协议为 v3，媒体库 schema 为 3、下载任务库 schema 为 2，与 0.1.0 相同；本次未新增迁移逻辑，也不会仅因应用版本号变化就清空同结构数据库。设备身份沿用 0.1.0 的 Android 系统标识方案。v1.0.0 前不承诺不同应用版本之间的行为或数据兼容；更早版本的旧随机 UUID 设备记录不迁移，记录不兼容时需清理并重新发现。

已安装同签名 release 版可覆盖安装：

```sh
adb install -r dist/0.2.0/Tamayura-0.2.0-android.apk
```

首次安装可去掉 `-r`，或将 APK 传到手机后通过文件管理器安装。若安装的是 debug 签名版本，需要先卸载；旧数据不兼容时也可清空应用数据或卸载重装。卸载会清除应用设置、SAF 目录授权、已记住的对端、离线缓存、下载记录和未完成分片；原始共享照片及已保存到外部接收目录的文件保留。

在同一 Wi-Fi 下打开双方应用，添加共享目录和接收目录，通过自动发现、手动 IP 或二维码连接。在接收端进入相册即可观察缩略图逐步出现与同步进度；来源端需要锁屏时，先开启「后台共享」。

## 已知限制与待验收

- 本次改善等待期间的反馈，未提高缩略图生成并发；几千张大照片的总同步耗时仍取决于媒体数量、解码能力、存储提供者与网络。真实双机的大相册首次同步、新增共享目录与增量同步需验收。
- 同步失败会撤销尚未提交的临时预览，保留上次完整缓存；首次同步失败时可能重新回到空相册。尚未提交的预览不提供跨失败、重启的持久续传。
- 仅支持 Android 16+ 和 IPv4 局域网，无账号、鉴权或 TLS；仅在可信局域网中使用。未提供其它平台安装包。
- 后台共享受 Doze、电池优化和厂商电源策略影响；不提供开机自启或纯局域网远程唤醒，强行停止后需主动打开。长时间锁屏、切换 Wi-Fi 与停止后省电效果仍需真机验收。
- 非实时扫描，只同步媒体增删，不处理文件内容编辑或跨设备内容去重；目录授权失效和真实扫描错误仍需恢复授权或移除失效目录。
- 未完成下载分片占用存储；外部保存成功后、数据库登记前若进程被强杀，可能留下未登记副本。系统停止任务或强行停止应用后需要回到应用重试。
- 真实双机的多目录授权、嵌套接收成功落盘、自动发现、扫码、断网恢复、通知关闭时下载和系统分享仍待验收。

正式公开发布前还需完成真机验收及干净环境重建；步骤见 [发布与打包](../发布.md)。
