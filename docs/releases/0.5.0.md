## 本版变更

- **降低下载占用**：有序分片直接写入接收目录，避免生成完整合并暂存，同卷峰值由约三倍降至约两倍；下载和保存前检查可查询的可用空间，容量未知时继续尝试并处理实际写入错误。保存失败保留分片，完整分片可在来源离线时重试保存。
- **暂停与清理**：区分「暂停下载」与「取消并删除」，显示已暂存字节，支持删除失败和暂停任务；清理等待旧任务与原生写入结束，启动时回收已完成、待删除及孤立暂存，保留可续传任务。超过最近 100 条的未完成任务仍可操作，已保存的接收文件不会随任务清理删除。
- **缩略图复用**：媒体库采用独立 `thumbnails` 表，正式与暂存目录共享图片；首次提交、目录增删和目录版本变化后的续传无需复制已有缩略图，同时保留元数据分页、断点、原子提交和无引用图片清理。
- **临时断线恢复**：范围流连续 30 秒无数据时关闭失效连接并从现有分片续传，取消固定的单流 30 分钟总时限。对端暂时不可用时显示「等待下载」和「稍后会自动重试」；Android 由 JobScheduler 退避重排，macOS / Windows 在进程内从 10 秒起退避，持续 30 分钟未收到数据才失败。有新字节时清除旧断线计时，避免恢复后再次暂停被过早判为失败。
- **重新扫描时继续共享**：来源端保留旧目录直到新扫描成功后整体替换；移除的共享目录立即停止提供，扫描失败或授权失效撤销共享。返回应用距最近成功扫描不足 30 秒时不重复扫描，手动刷新和增删目录仍立即扫描，失败后的下一次激活立即重扫。
- **异常与竞争修复**：macOS 单个媒体删除、大小变化或无法解码时返回空缩略图，让其它条目继续同步；目录和授权错误仍报告，原文件下载仍严格校验。修复任务删除与最终保存竞争导致完成标记丢失、Android 旧读取的迟到权限异常撤销新目录的问题。
- **发布维护**：明确禁止把开发、打包和测试环境的隐私信息记录到项目或发布说明中。发布包从不含个人信息的通用临时源码目录构建，并在交付前完成产物中的环境隐私标记扫描。三平台使用相同版本与构建号，沿用本地试用发布方式。
- **macOS 打包隐私**：打包流程去除主程序原生调试符号，避免记录插件缓存的个人路径，随后按项目 `Release.entitlements` 重新进行 ad-hoc 签名。流程仅接受 ad-hoc 输入，拒绝覆盖其它签名；最终签名权限与项目声明的六项一致，不含 `get-task-allow`，原包和解压副本验签通过。
- **测试可移植性**：修正 Windows 发布检查发现的两处测试环境假设，临时路径改用平台路径拼接，Android worker 测试先设置平台 mock 和独立数据库目录。业务断言与应用代码保持不变。

完整变更见 [CHANGELOG](../../CHANGELOG.md)，实现见 [下载存储与清理](../下载存储与清理.md)、[缩略图存储](../缩略图存储.md)、[传输恢复](../传输恢复.md) 和 [单张缩略图容错](../单张缩略图容错.md)。

## 安装与数据

互联设备应使用相同的 **0.5.0**。协议保持 v3，**媒体库升至 schema 5、下载任务库升至 schema 3，旧库直接清空重建，不提供迁移**：

- 媒体库重建清空设置、记住的设备、离线相册与缩略图、下载历史索引，需重新选择共享和接收目录并发现设备。
- 下载任务库重建清空任务列表；旧的未完成分片不再关联任务，由启动清理回收。
- **外部原始媒体和已保存的接收文件保留。** 任务清理也不会删除已保存的接收文件。

v1.0.0 前允许覆盖安装，但不承诺旧数据、配置或不同版本之间兼容；遇到不兼容可清理应用数据或卸载重装，不增加历史迁移和回退逻辑。

Android 同签名 release 可覆盖安装：

```sh
adb install -r dist/0.5.0/Tamayura-0.5.0-android.apk
```

debug 与 release 签名冲突时需先卸载。卸载会清除设置、SAF 授权、离线缓存、下载记录和未完成分片。macOS 完整解压 ZIP，将 `Tamayura.app` 放入“应用程序”；未公证包若被系统拦截，在确认来源和校验后通过“隐私与安全性”确认打开，无需关闭全局 Gatekeeper。

Windows ZIP 须完整解压，不单独复制 EXE，并安装相应 Visual C++ x64 运行库；首次连接仅对可信专用网络授权防火墙。

## 已知限制

- 直存仍需要分片与接收文件同时存在，峰值约两倍；容量预检不预留磁盘，Android 文档提供者可能无法报告接收容量。保存成功与数据库登记之间若进程被强制终止，可能留下完整但未登记的副本，重试可能重名另存。
- 停滞判定需要连续 30 秒无数据；持续 30 分钟没有收到数据后仍需手动重试。文件删除、大小变化、来源目录失效等不可恢复错误立即失败。
- 真实跨设备下载、锁屏、合盖、切后台、Wi-Fi 漫游、磁盘写满、强制终止及恢复仍待验收；自动化检查不替代这些场景。
- Android 后台共享受 Doze 和厂商电源策略约束；macOS / Windows 共享和下载依赖应用运行且系统清醒，退出或睡眠会中断，不提供退出后常驻、开机自启或防睡眠。
- macOS Sequoia / Intel 实机、Windows 10 1809、无开发工具的用户机、完整 GUI、实际 DNS-SD 与防火墙、系统目录授权和分享仍待验收。
- Windows 当前仅 x64，不提供相机扫码、系统分享面板或安装器；UNC/网络路径、符号链接、目录联接及 OneDrive 等重解析占位文件不支持。
- Android 使用本地 release 证书，macOS 为 ad-hoc 未公证包，Windows ZIP 未签名；本地试用交付不代表稳定版或应用商店发布。
- 仅可信 IPv4 局域网，无账号、鉴权或 TLS；不提供纯局域网远程唤醒，远端 CI 尚未执行。
