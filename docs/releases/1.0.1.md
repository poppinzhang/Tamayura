# Tamayura 1.0.1

版本日期：2026-10-28。

**发布准备中。** 当前统一版本为 **1.0.1+17**；完整本地测试、Android/macOS 打包、四个平台分支 CI（Linux 含 x64、arm64）、Tag 工作流与远端发布核验均待完成。本页将记录本次实际结果，不以开发阶段检查或此前版本结果代替发布门槛。

## 本版变更

- 修复 Windows 重启后的共享目录扫描阻塞网络启动与目录操作：先开启 gRPC 和设备发现，后台恢复独立的本机索引并核对增删，有效缓存恢复后可继续提供文件。首次无缓存时，目录请求明确报告尚未就绪，保留对端离线相册。
- 修复 Windows 重复启动形成多个实例：同一用户及登录会话内唤回已有窗口，保留页面、下载和最大化状态；启动竞争、超时及权限错误有明确处理。
- 修复 Android 在基于 Wi-Fi / 以太网的 VPN 或 TUN 下后台下载可能一直等待的问题，继续拒绝纯蜂窝网络，不修改系统 VPN 路由。
- 保持 v1.0.0 的 schema 7/3、配置格式和 gRPC v4；Windows 本机索引独立保存，损坏或较新索引保留原文件并报告错误。

完整改动及限制见根目录 [CHANGELOG](../../CHANGELOG.md) 的 `1.0.1` 段落；实现见 [Windows 本机目录索引](../Windows本机目录索引.md)、[桌面托盘与窗口生命周期](../桌面托盘与窗口生命周期.md) 和 [Android 16+](../android16.md)。

## 安装与数据

- 从 v1.0.0 升级沿用媒体库 schema 7、下载任务库 schema 3、现有配置及协议 v4。设置、目录授权、设备记录、离线相册、下载历史与未完成任务继续保留；不清空重建，也不要求卸载正式版。未知或不支持的数据库版本明确拒绝并保留数据，详见 [兼容与升级](../兼容与升级.md)。
- Android 沿用现有 release 签名，同签名正式版可覆盖安装。更早不同签名或 debug 包不能作为同签名升级路径；卸载会清除应用数据、目录授权与未完成分片，不能承诺保留这些内容。
- Windows v1.0.0 进程未参与新的单实例机制，首次运行本版前先从托盘退出旧版。保留完整发行目录，自动更新要求应用目录及父目录可写；用户数据不因替换应用目录而删除。首次没有本机索引缓存，仍需完成扫描才能共享，后续可先恢复有效缓存。
- macOS 完整替换 App；未公证包如被系统拦截，在确认来源及校验结果后使用系统“隐私与安全性”的打开方式，不关闭全局 Gatekeeper。Linux 完整解压后运行，移动程序目录后重新运行 `install-desktop-entry.sh`；设置与用户数据保留在原 XDG 目录。
- 更新会中断共享与传输，重新启动后可重试任务。应用内更新可发现正式 Release，Android 仍需系统安装确认，macOS/Linux 通过 Release 页面手动更换程序。

## 已知限制与验收边界

- 尚未完成真实 Windows 万张 ARW 的启动耗时、磁盘性能、窗口焦点和跨设备传输验收，也未完成 Android VPN / TUN 下系统任务启动与双向原文件互传验收。平台通道仍一次传回完整轻量元数据，不能承诺未经测量的启动耗时或帧率。
- 真实安装升级、Wi-Fi 发现、目录权限、断网/睡眠恢复、系统菜单、扫码和分享的完整验收仍待进行。Flutter 回环、原生宿主测试及无头 CI 不能替代这些场景。
- macOS 未公证，Windows 与 Linux 未签名。Android 后台共享受系统电源策略限制；桌面要求应用存活且系统清醒，Linux 无可用托盘时关闭窗口即退出。Linux 发现依赖 Avahi，中日文与媒体预览分别依赖系统字体及解码器。
- Windows/Linux 没有相机扫码或系统分享面板，iOS 尚无运行或发布工程。仅用于可信 IPv4 局域网，无账号、鉴权或 TLS，不跟踪原文件内容修改、不自动下载整本相册、不跨设备去重。
