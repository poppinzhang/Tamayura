# Tamayura 0.9.6 Pre-release

版本日期：**2026-10-21**。Android、macOS 与 Windows 统一使用 **0.9.6+15**，Windows EXE 数字版本为 **0.9.6.15**。

**当前状态：发布准备中。** 本版包含 0.9.5 未公开发布的全部功能，并修复 Windows 更新回归的临时目录清理竞态。0.9.5 的 Tag 工作流连续三次在该处失败，未创建公开 Release，原 Tag 保留不动，实际结果见 [0.9.5 发布记录](0.9.5.md)。0.9.6 的最终源码提交、完整测试、打包、三平台分支 CI、Tag 工作流和远端发布均待完成；此前版本的通过结果不能替代本次验证。

## 本版变更

完整说明见 [CHANGELOG 0.9.6](../../CHANGELOG.md#096)，计划的 Release 正文取自 Tag 内该版本段落。

- 图片预览支持顺时针、逆时针每次旋转 90 度；只改变查看角度，切换后重置旋转与缩放，不修改原文件。视频继续显示缩略图并通过系统应用播放。
- 预览支持左右滑动及上一项、下一项按钮，首尾不循环。相册按打开时当前合集与排序的完整身份索引跨分页浏览，下载页保留打开时的任务顺序；只下载当前访问且未保存、未运行的项目，复用已有文件和任务，不预下载邻项，切换或关闭预览后下载继续。动画、手势和异步容错见[媒体预览与切换](../媒体预览与切换.md)。
- 相册、设备与设置主菜单支持双击回顶，覆盖手机和桌面导航，保留合集、筛选与其他页面位置；减少动画时直接回顶。
- 共享 Flutter 界面统一使用官方 `material_ui`、Lucide、`flutter_animate` 和 `animations` 3.x，保留 Material 3、中性色主题、标签状态、提示停留时间、预览手势和 Android 预测返回，响应减少动画及无障碍导航，详见 [UI 组件与动效](../UI组件与动效.md)。
- macOS 原生图片解码按扩展名提供 ImageIO 类型提示，修复部分 Sony ARW 经文件描述符读取时被误识别为 TIFF、无法预览的问题；来源端缩略图共用修复，仍依赖系统的 RAW 格式支持。实现与回归范围见 [macOS 原型](../macOS原型.md#arw-图片缩略图与本地预览)。
- Windows 更新测试读取 ready 中的 helper 进程 ID 并持有句柄，等待退出且核验退出码后再清理临时目录；短暂占用时限时重试，超时、非零退出码和永久清理错误仍使测试失败，整体通过提示在清理完成后输出。不改变应用安装或回滚逻辑；实现见[应用更新](../应用更新.md)。

## 安装与数据

- 保持媒体库 **schema 7**、独立下载任务库 **schema 3** 和通信协议 **v4**，不因本次预览、界面或测试调整主动重建数据库，不保存旋转偏好或改写原文件。v1.0.0 前不保证旧数据或跨版本兼容，互联设备应使用同一构建。
- Android 沿用 0.6.1 起的专用 release 签名及现有 CI Secrets；同签名包可覆盖安装。旧签名或 debug 包冲突时需自行卸载，应用不自动卸载；卸载会清除应用数据、目录授权、下载记录和未完成分片，外部共享原文件及已保存接收文件保留。
- 已安装 0.8.0 或更新版本的设备可在本版发布后使用「检查更新」。Android 需要系统授权与安装确认；Windows 须完整发行目录及父目录可写，保留 DLL、`data`、更新脚本和清单；macOS 通过 Release 页面手动替换完整 App。更早版本须手动升级。
- Windows 的目录权限、PowerShell 策略或文件占用可能阻止更新，需按提示处理或手动升级。目录回滚不保证数据库恢复或应用业务状态健康。macOS 未公证包受系统拦截时应核对来源，再使用系统提供的确认方式，不关闭全局 Gatekeeper。
- 更新会中断共享与传输，重新打开后可重试；不承诺数据迁移或无缝续传。

## 已知限制与验收边界

- 本次 Windows 修复仅处理测试同步与清理；生产更新 helper 仍可能留下空缓存目录，不影响已完成的程序替换、重启或用户媒体。
- 图片旋转仅影响查看角度，视频仍通过系统应用播放；不预下载相邻媒体，已有下载继续，可在下载页暂停或取消。macOS RAW 解码取决于系统、相机型号、编码和文件状况，不保证所有 RAW 均可解码。
- 真实覆盖安装、三平台预览与触控板手势、减少动画、屏幕阅读器、大图内存及解码速度、系统视频播放、Wi-Fi 发现、目录权限、跨设备原文件传输、断网/睡眠恢复、系统菜单、扫码和分享尚待验收；原生宿主测试与回环 gRPC 不能替代。
- macOS 仍为 ad-hoc 签名且未公证，Windows 未签名；Windows 不提供相机扫码或系统分享面板。Android 后台共享受系统电源策略影响，桌面要求应用存活且系统清醒；Linux 和 iOS 尚无可运行或发布工程。
- 已保存错误保留原语言，Android 已运行的下载引擎可能继续使用启动时语言，部分系统界面跟随系统语言，详见[多语言](../多语言.md)。
- 仅用于可信 IPv4 局域网，无账号、鉴权或 TLS。Pre-release 不代表稳定公开发行或应用商店版本。
