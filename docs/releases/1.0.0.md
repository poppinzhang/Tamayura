# Tamayura 1.0.0

版本日期：2026-10-22。

**当前状态：正式发布准备中，尚未创建 v1.0.0 Tag 或公开 Release。** 本次完整测试、Release 打包、四平台分支 CI 与 Tag 发布仍待执行；本文件不将开发阶段测试或历史版本结果作为发布成功的证据。

## 本版变更

- 首个正式版本；此后 GitHub 发布均为正式 Release 并标记 Latest，历史 0.x Pre-release 与 Tag 保持原状。
- 新增 Linux x64 / arm64，包含 GTK 目录选择、Avahi 发现、媒体预览、离线相册、并发下载、托盘与桌面入口；修复多网卡失效地址和深层保存路径问题。
- 更新应用内、macOS 菜单栏与 Linux 托盘的「響」品牌图像，保留原有应用启动图标和 Windows 托盘图标。
- 正式版兼容基线固定为媒体库 schema 7、下载任务库 schema 3、协议 v4；不支持的数据库版本安全拒绝并保留数据，取消自动清空重建。
- 应用内更新仅选择正式 Release 与正式发布清单，后续数据库、配置和协议变化须按[兼容与升级](../兼容与升级.md)验证升级和异常恢复。

完整功能、改进、修复与限制以 Tag 内 [CHANGELOG](../../CHANGELOG.md) 的 `1.0.0` 段落为准。

## 安装与数据

- Android 沿用 0.6.1 起的 release 签名，同签名包可覆盖安装。更早不同签名或 debug 包冲突时需自行卸载；卸载清除应用数据与目录授权，外部共享原文件和已保存接收文件保留。
- 0.9.6 已使用本版基线 schema 7/3，相同结构的数据继续读取。本版不改变协议 v4；更旧 schema 或未知较新 schema 不提供自动迁移，也不会删除数据，需先备份并依据错误处理。正式版之后的升级必须验证数据保留与迁移，不能依赖清库。
- macOS 完整解压 App，遇到系统拦截时确认来源及校验结果后使用系统“隐私与安全性”提供的打开方式，不关闭全局 Gatekeeper。
- Windows 必须保留完整 Release 目录；自动更新要求应用目录及父目录可写，不自动提权。Linux 完整解压后运行 `tamayura`，可运行 `install-desktop-entry.sh` 添加当前用户的应用菜单入口；检查更新打开 Release 页面，手动替换程序目录。
- 1.0.0 发布后，0.8.0 或更新版本可通过应用内检查更新找到本版；更早版本手动安装。更新会中断共享与传输，重启后可重试媒体下载。

## 已知限制与验收边界

- 当前缺少本版正常 GUI、真实安装更新、Wi-Fi 发现、目录权限、跨设备传输、断网/睡眠恢复、系统菜单、扫码和分享的完整真机验收。历史容器、回环 gRPC 与原生宿主测试不代替这些场景。
- Linux 的 GNOME / KDE、X11 / Wayland、真实托盘宿主与跨平台真机互传尚待验证；自动发现依赖 Avahi，中文和日文依赖系统字体，媒体格式依赖系统解码器。无托盘时关闭窗口会退出。
- macOS 未公证，Windows 与 Linux 未签名；Android 后台共享受电源策略限制，桌面要求应用存活且系统清醒。Windows/Linux 无相机扫码和系统分享面板，iOS 尚无运行和发布工程。
- 仅用于可信 IPv4 局域网，无账号、鉴权或 TLS。不跟踪原文件内容修改，不自动下载整本相册，不进行跨设备内容去重。

发布后的实际结果补充于此；不移动既有 Tag，也不把后续结果倒写成发布准备时已经通过。
