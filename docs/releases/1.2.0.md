# Tamayura 1.2.0

版本日期：2026-11-18。

当前处于 **v1.2.0 发布准备阶段**：统一版本更新为 **1.2.0+19**（Windows 数字文件版本为 `1.2.0.19`）。本地完整测试、打包、四平台分支 CI、Tag 推送及远端 Release 发布尚未完成；本页先记录发布目标、验证计划、兼容范围与已知限制，实际结果将在发布完成后补充。

## 本版变更

- 新增可选的 Tailscale 互联网访问：独立 Flutter-Tailscale SDK 与 Go tsnet 运行时内嵌于应用，设置中可选登录、恢复状态与退出。未登录时不创建 helper、不启动节点、不探测远端，LAN 启动、发现与同步保持独立。
- 通过身份专用端口发现可见的 Tamayura 节点；用户确认后绑定 tailnet 范围、稳定节点与 Tamayura 设备身份，媒体端口只接受已确认且经 WhoIs 核验的来源。每台设备分别显示 LAN 与 Tailscale 在线状态，相册同步批准仍独立。
- 远端传输沿用目录分页、缩略图、原文件单流 / 四路并发下载与分片续传；LAN 初次连接短暂失败可改用 Tailscale 绑定，身份、协议或权限错误不换路。Android 已绑定远端的下载任务增加蜂窝网络候选。
- 新增中日英设置界面、移动数据提示、远端共享确认与撤销。接入开发期间发现的问题已修复：会话证书固定有效期、节点启动就绪等待与冷启动后台下载、对端重新登录后的重新关联、Linux 打包核验静态 helper 等，详见 CHANGELOG。
- 沿用 v1.0.0 起的媒体库 schema 7、下载任务库 schema 3 和 gRPC v4；Tailscale 启用状态与绑定保存在现有设置表，不新增迁移，不清空或迁移已有用户数据。

完整改动及限制见 `CHANGELOG.md` 的 `1.2.0` 段落；实现细节、安全边界与验证范围见 [Tailscale 实现](../Tailscale实现.md)，需求与验收目标见 [Tailscale 接入需求](../Tailscale接入需求.md)。

## 安装与数据

- 从 v1.1.0 或其他正式版升级沿用媒体库 schema 7、下载任务库 schema 3、现有配置及协议 v4。设置、目录授权、设备记录、离线相册、下载历史与未完成任务继续保留；不清空重建，也不要求卸载正式版。Tailscale 启用状态与远程共享绑定新增在现有设置表中，无需迁移；未知版本、损坏或冲突的绑定记录保留原数据并只停用远程模块，详见 [兼容与升级](../兼容与升级.md)。
- 升级后默认不登录 Tailscale：不创建 helper、不启动节点、不探测远端；只有在设置中主动登录才会创建本机节点状态（应用私有数据目录下的 `tailscale-node`）。退出会清除本机登录凭据并保留设备、离线相册、下载文件与分片，不会从 Tailscale 管理后台删除节点。
- 互联网访问需要两端设备都登录 Tailscale 并能在同一 tailnet 内互相访问，tailnet 访问策略须允许 Tamayura 的虚拟端口 50728 与 50729；两端还需分别确认远程共享。登录前会提示移动数据可能产生流量费用。
- Android 沿用现有 release 签名，同签名正式版可覆盖安装。更早不同签名或 debug 包不能作为同签名升级路径；卸载会清除应用数据、目录授权与未完成分片，不能承诺保留这些内容。
- macOS 完整替换 App（含内嵌 helper）；未公证包如被系统拦截，在确认来源及校验结果后使用系统“隐私与安全性”的打开方式，不关闭全局 Gatekeeper。Windows 与 Linux 保留完整发行目录（含 Tailscale helper 与许可证声明），不能只复制主程序；Linux 移动程序目录后重新运行 `install-desktop-entry.sh`，Windows 自动更新要求应用目录及父目录可写。设置与用户数据保留在原目录。
- 更新会中断共享与传输，重新启动后可重试任务。应用内更新可发现正式 Release，Android 仍需系统安装确认，macOS/Linux 通过 Release 页面手动更换程序。

## 已知限制与验收边界

- 内嵌 Tailscale 节点尚未在真实账号和设备上完成验收：官方登录 / 审批 / 到期、两端逐台授权、Android 蜂窝 UIDT 与锁屏、Wi-Fi 切换、桌面睡眠恢复、直连及 DERP 路径、中大文件校验与真实升级仍待验证。此前仅用独立官方 Tailscale 客户端在台式机与手机之间验证过互联网直连线路，不能代替内嵌节点验收；冷启动的后台下载、连续运行 30 天以上与对端重新登录后的重新关联目前只有自动化覆盖。
- 已按仅 Wi-Fi / 以太网排队的 Android 下载任务不会在之后补加蜂窝网络，需取消后重新下载；当前没有独立的计费网络自动同步开关。Headscale、系统 VPN、iOS、Flutter Web、UDP、Funnel、exit node、自建控制服务器和直接公网服务均未实现。
- 尚未完成 Android、macOS、Windows、Linux 之间的真实安装升级、Wi-Fi 发现、目录权限、断网/睡眠恢复、系统菜单、扫码与分享的完整验收。Flutter 回环、原生宿主测试及无头 CI 不能替代这些场景。
- macOS 未公证，Windows 与 Linux 未签名。Android 后台共享受系统电源策略限制；桌面要求应用存活且系统清醒，Linux 无可用托盘时关闭窗口即退出。Linux 发现依赖 Avahi，中日文与媒体预览分别依赖系统字体及解码器。
- Windows/Linux 没有相机扫码或系统分享面板，iOS 尚无运行或发布工程。LAN 入口仍仅用于可信 IPv4 局域网，无应用层鉴权或 TLS，禁止公开端口映射；Tailscale 路径提供隧道加密及已批准节点的访问控制，但不保护 LAN 监听。不跟踪原文件内容修改、不自动下载整本相册、不跨设备去重。
