# Tamayura 0.9.5 Pre-release

版本日期：**2026-10-21**。Android、macOS 与 Windows 统一使用 **0.9.5+14**，Windows EXE 数字版本为 **0.9.5.14**。

**当前状态：发布准备中。** 本记录随版本准备提交建立；目标提交的完整测试、Release 打包、三平台分支 CI、附注 Tag 与远端发布均待完成。此前功能开发检查、历史版本通过结果及已有安装包不能替代本版验证。发布后的实际提交、Actions 结果与附件核验补充到本文，不改写已发布 Tag。

## 本版变更

完整说明见 [CHANGELOG 0.9.5](../../CHANGELOG.md#095)，Release 正文使用 Tag 内该版本段落。

- 图片预览支持顺时针、逆时针每次旋转 90 度；只改变当前查看角度，切换后重置旋转与缩放，不修改原文件。
- 媒体预览支持左右滑动及上一项、下一项按钮。相册使用打开时当前合集与排序的完整身份索引，支持跨分页；下载页保留打开时的任务顺序。只下载当前访问且未保存、未运行的项目，复用已保存文件和现有任务，切换或关闭预览后下载继续。交互、动画与异常处理见[媒体预览与切换](../媒体预览与切换.md)。
- 相册、设备和设置主菜单支持双击回到各自页面顶部，覆盖手机和桌面导航；单击保留位置，双击不改变合集及筛选，减少动画时直接回顶。
- 共享 Flutter 界面统一使用官方 `material_ui`、Lucide 图标、`flutter_animate` 和 `animations` 3.x；保留 Material 3、中性色主题、标签状态、预览手势与 Android 预测返回，响应减少动画和无障碍导航。实现见 [UI 组件与动效](../UI组件与动效.md)。
- macOS 图片解码按原文件扩展名提供 ImageIO 类型提示，修复部分 Sony ARW 经文件描述符读取时被误识别为 TIFF、无法显示本地原图的问题；来源端缩略图共用修复，仍受系统 RAW 格式支持范围限制。实现见 [macOS 原型](../macOS原型.md#arw-图片缩略图与本地预览)。

## 安装与数据

- 本版保持媒体库 **schema 7**、独立下载任务库 **schema 3** 与通信协议 **v4**，不因本次预览和界面调整主动重建数据库，不保存旋转偏好或改写原文件。v1.0.0 前仍不保证旧数据及跨版本互联兼容，互联设备应使用同一构建。
- Android 沿用 0.6.1 起的专用 release 签名和现有 CI Secrets；同签名 release 包可覆盖安装，旧签名包或 debug 包冲突时须自行卸载，更新功能不自动卸载。卸载会清除应用数据、SAF 目录授权、缓存、下载记录、任务及未完成分片，外部共享原文件与已保存接收文件保留。
- 已安装 0.8.0 或更新版本的设备可在本版发布后使用「检查更新」。Android 仍需系统安装授权与确认；Windows 须完整发行目录及父目录可写，不能只保留 EXE，不自动请求管理员权限；macOS 通过 Release 页面手动替换完整 App。更早版本须手动升级，要求见[应用更新](../应用更新.md)。
- Windows 的受保护目录、系统 PowerShell 策略或文件占用可能阻止更新，需按提示处理或手动升级。程序目录回滚不等于数据库回滚，也不表示新程序已通过完整启动健康检查。
- macOS 未公证包被系统拦截时，应确认来源与校验结果，再使用系统“隐私与安全性”提供的确认方式，不关闭全局 Gatekeeper。
- 更新会中断共享与传输，重新打开后可重试中断任务；不承诺数据库迁移或无缝续传。

## 已知限制与验收边界

- 图片预览旋转仅影响查看角度，视频仍显示缩略图并通过系统应用播放。切换只下载当前访问项，不预下载相邻媒体；已开始的下载可通过下载页暂停或取消。
- macOS RAW 解码取决于 ImageIO 对系统版本、相机型号、编码及文件状况的支持；部分 Sony ARW 的开发样本结果不代表所有 RAW 或真实应用界面验收。
- 三平台的实际触摸、触控板、横竖图片、减少动画、屏幕阅读器、大图内存与解码速度、系统视频播放及来源离线行为仍需真机验收。
- 真实覆盖安装、Wi-Fi 发现、目录权限、跨设备原文件传输、断网/睡眠恢复、系统菜单、扫码与分享尚未完成本版验收。原生宿主检查和回环 gRPC 不能替代正常 GUI 与跨设备测试。
- Android 后台共享受系统电源策略影响；macOS、Windows 需要应用存活且系统清醒。Windows 不提供相机扫码或系统分享面板。macOS 未公证、Windows 未签名；Linux 和 iOS 尚无可运行或发布工程。
- 既有多语言边界继续适用：已保存错误保留原语言，Android 已运行的下载引擎可能继续使用启动时语言，部分系统界面跟随操作系统语言，详见[多语言](../多语言.md)。
- 当前仅用于可信 IPv4 局域网，无账号、鉴权或 TLS。Pre-release 不代表稳定公开发行或应用商店版本。
