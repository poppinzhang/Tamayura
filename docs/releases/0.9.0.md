## 本版变更

完整说明见 [CHANGELOG 0.9.0](../../CHANGELOG.md#090)，Release 正文使用 Tag 内该版本段落。

- 新增简体中文、日本語与 English 界面，默认按系统首选语言解析；可在「设置 → 外观 → 语言」选择固定语言并保留偏好。界面、Material 组件、日期与数量格式、服务提示和三平台原生文案的范围见[多语言](../多语言.md)。macOS 相机及本地网络权限说明提供三种语言，由系统选择。
- 语言保存失败时保留原选择并提示重试；目录重叠、文件变化和扫描取消使用当前语言解释。
- 修复下载空页面在较长文案及窄屏大字号下溢出、打开的媒体详情未随语言变化更新的问题，补充三语言布局和动态切换回归。
- 修复 Windows 托盘语言测试缺少头文件声明的问题，补充文案完整性及各平台原生语言测试；修复未初始化控制器的语言测试未关闭数据库，导致 Windows 临时目录清理失败的问题。

## 发布前失败与修正

首个准备提交 `ba709e0dd6c12a1317f0e056fea7429ec2e24500` 的本地 Android 与 macOS 流程通过，但 [Windows 分支 CI](https://github.com/poppinzhang/Tamayura/actions/runs/39130050510) 在 Flutter 测试阶段失败：876 项通过，2 项在清理临时目录时报文件占用错误。两项用例均未初始化控制器，测试预先创建的数据库未被控制器接管和关闭；Windows 不允许删除仍打开的数据库文件。

最终提交 `1523ddd39a8658b7aa95da55caa8f8027ed64309` 让测试夹具明确关闭自己创建的数据库，不再依赖控制器是否初始化。修正后重新提交、推送，并对新提交重新完成全部发布工具检查、本地 Android 与 macOS 打包及核验，以及三平台分支 CI；全部通过后才创建 `v0.9.0`。旧提交结果未替代最终提交验证，未给首个失败提交打 Tag 或发布附件，也未移动版本 Tag。

## 安装与数据

- 本版保持媒体库 **schema 7**、独立下载任务库 **schema 3** 和通信协议 **v4**，不因多语言功能主动重建数据库。语言保存在已有设置表，首次默认为跟随系统；Android、macOS 原生层也保存语言偏好。v1.0.0 前仍不保证旧数据及跨版本互联兼容，互联设备应使用同一构建。
- Android 沿用 0.6.1 起的专用 release 签名和当前 CI Secrets，本轮验签通过，同签名 release 包可覆盖安装；0.5.0 及更早旧签名包、debug 包不能直接覆盖。签名冲突时更新功能只报告错误，不自动卸载。用户自行卸载会清除应用数据、SAF 目录授权、缓存、下载记录、任务及未完成分片；外部共享原文件与已保存接收文件保留。
- 已安装 0.8.0 的设备可使用「检查更新」。Android 仍需系统安装授权与确认；Windows 需完整发行目录及父目录可写，保留 DLL、`data`、更新脚本和文件清单，不能只保留 EXE，不自动请求管理员权限；macOS 仍通过 Release 页面手动替换完整 App。更早版本须手动升级，安装要求见[应用更新](../应用更新.md)。
- Windows 的受保护目录、系统 PowerShell 策略或文件占用可能阻止更新，需按提示处理或手动升级。程序目录回滚不等于跨版本数据库回滚，也不表示新程序已通过完整启动健康检查。
- macOS 未公证包被系统拦截时，应确认来源与校验结果，再使用系统“隐私与安全性”提供的确认方式，不关闭全局 Gatekeeper。
- 更新会中断共享与传输，重新打开后可重试中断任务；不承诺数据库迁移或无缝续传。

## 已知限制与验收边界

- 已保存的任务错误、后台共享失败原因及 Android 更新安装状态保留写入时语言。Android 已运行的后台下载引擎不接收后续应用内语言切换，新生成的任务错误可能沿用启动时语言；后续新建引擎读取最新偏好，文件传输不受影响。
- macOS 权限弹窗按系统语言选择；应用主菜单沿用模板英文。系统文件选择器按钮和分享面板不跟随应用内选择；Windows 部分内部存储诊断仍为英文。繁体中文使用简体中文，日文与英文翻译尚未专业校对。
- macOS 为 ad-hoc 签名且未公证，Windows 未签名；当前为试用性质的 Pre-release，不是稳定版或应用商店发行。SHA-256 证明下载完整性，不能描述成 Windows 的独立发布者签名。
- Windows 既有更新缓存清理限制仍见 [0.8.0 发布记录](0.8.0.md#已知限制与验收边界)：辅助进程可能留下空 GUID 缓存目录，更新测试最终清理仍存在既有时序竞争；本次语言测试的数据库关闭修复不等于修复该更新清理问题。
- 三平台字体、多语言通知及系统菜单、真实覆盖安装、自动发现、目录授权、跨平台原文件传输、断网/睡眠恢复、扫码与系统分享尚未完成本版真机验收；Windows 不提供相机扫码或系统分享面板。Sequoia / Intel、Windows 10 1809 与无开发工具用户机不能据自动化测试存在而认定通过。
- Android 后台共享受系统电源策略及厂商限制影响，桌面共享与下载要求应用存活且系统清醒；不新增后台系统服务、开机自启或远程唤醒。媒体同步仍仅限可信 IPv4 局域网，无账号、鉴权或 TLS；检查更新需要互联网访问 GitHub。
