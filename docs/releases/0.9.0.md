# Tamayura 0.9.0 Pre-release

版本日期：**2026-10-18**。发布目标为 Android、macOS 与 Windows 统一使用 **0.9.0+13**，Windows EXE 数字版本为 **0.9.0.13**。

**当前状态：准备发布，尚未完成发布提交的完整验证、打包和远端发布。** 本文记录本次范围及待办状态；此前功能开发或历史版本的测试不能代替最终发布提交的验证。安装包暂未确认可用，当前可下载版本仍为 [0.8.0 Pre-release](https://github.com/poppinzhang/Tamayura/releases/tag/v0.8.0)。

## 本版范围

完整版本说明以 [CHANGELOG 0.9.0](../../CHANGELOG.md#090) 为准，Release 正文将使用 Tag 内对应段落。

- 新增简体中文、日本語与 English 界面，默认按系统首选语言解析；可在「设置 → 外观 → 语言」选择固定语言并保留偏好。界面、日期与数量格式、服务提示和三平台原生文案的范围见[多语言](../多语言.md)。
- 语言保存失败时保留原选择并提示重试；目录重叠、文件变化和扫描取消使用当前语言解释。
- 修复下载空页面在较长文案及窄屏大字号下溢出、打开的媒体详情未随语言变化更新的问题，补充三语言布局和动态切换回归。
- 修复 Windows 托盘语言测试缺少头文件声明的问题，补充文案完整性及各平台原生语言测试。

## 发布前修正

首个准备提交 `ba709e0dd6c12a1317f0e056fea7429ec2e24500` 的本地 Android 与 macOS 流程通过，但 [Windows 分支 CI](https://github.com/poppinzhang/Tamayura/actions/runs/39130050510) 在 Flutter 测试阶段失败：876 项通过，2 项在清理临时目录时报文件占用错误。两项用例均未初始化控制器，测试预先创建的数据库未被控制器接管和关闭；Windows 不允许删除仍打开的数据库文件。

测试夹具需明确关闭自己创建的数据库，不依赖控制器是否初始化。修正后重新提交、推送，并对新提交重复完整本地打包及三平台分支 CI；旧提交结果不替代最终提交验证。发现问题时尚未创建 `v0.9.0` Tag，未发布任何附件。

## 安装与数据

- 本版保持媒体库 **schema 7**、独立下载任务库 **schema 3** 和通信协议 **v4**，不因多语言功能主动重建数据库。语言保存在已有设置表，首次默认为跟随系统；Android、macOS 原生层也保存语言偏好。v1.0.0 前仍不保证旧数据及跨版本互联兼容，互联设备应使用同一构建。
- Android 沿用 0.6.1 起的专用 release 签名和当前 CI Secrets，计划支持同签名 release 包覆盖安装；最终签名以本轮核验为准。0.5.0 及更早旧签名包、debug 包不能直接覆盖，卸载会清除应用数据、目录授权及未完成分片；外部共享原文件与已保存接收文件保留。
- 已安装 0.8.0 的设备可在本版发布后使用「检查更新」。Android 仍需系统安装授权与确认；Windows 需完整发行目录及父目录可写，保留 DLL、`data`、更新脚本和文件清单；macOS 仍通过 Release 页面手动替换完整 App。更早版本须手动升级，安装要求见[应用更新](../应用更新.md)。
- 更新会中断共享与传输，重新打开后可重试中断任务；不承诺数据库迁移或无缝续传。

## 已知限制与验收边界

- 已保存的任务错误、后台共享失败原因及 Android 更新安装状态保留写入时语言。Android 已运行的后台下载引擎不接收后续应用内语言切换，新生成的任务错误可能沿用启动时语言；后续新建引擎读取最新偏好，文件传输不受影响。
- macOS 权限弹窗按系统语言选择；应用主菜单沿用模板英文。系统文件选择器按钮和分享面板不跟随应用内选择；Windows 部分内部存储诊断仍为英文。繁体中文使用简体中文，日文与英文翻译尚未专业校对。
- macOS 为 ad-hoc 签名且未公证，Windows 未签名；当前为试用性质的 Pre-release，不是稳定版或应用商店发行。Windows 既有更新缓存清理限制仍见 [0.8.0 发布记录](0.8.0.md#已知限制与验收边界)。
- 三平台字体、多语言通知及系统菜单、真实覆盖安装、自动发现、目录授权、跨平台原文件传输、断网/睡眠恢复、扫码与系统分享尚未完成本版真机验收；Windows 不提供相机扫码或系统分享面板。
- Android 后台共享受系统电源策略影响，桌面共享与下载要求应用存活且系统清醒。媒体同步仍仅限可信 IPv4 局域网，无账号、鉴权或 TLS；检查更新需要互联网访问 GitHub。
