# Tamayura 0.0.1 试用版本

日期：**2026-10-09**。

这是 Tamayura · 玉响的首个本地签名试用版本，用于在自己的 Android 手机之间体验局域网相册与按需下载。它尚未完成真实双机验收，不作为稳定版或公开上线版本。

## 可以试用的功能

- 中文相册、设备和设置页面；通过 mDNS + DNS-SD 自动发现，或手动输入 IPv4、扫描连接二维码。
- 自行选择共享目录与接收目录；保存设备信息、远端媒体元数据、缩略图和下载记录，离线也可浏览缓存。
- 分页浏览相册，按版本同步目录增删，为新增媒体获取缩略图；无需先下载整个相册。
- 点一次图片或视频即创建下载任务，同时打开预览。大于 50 MiB 的文件采用四路 gRPC 范围流，并保留分片供中断后续传。
- Android UIDT 后台接收、进度通知、下载任务列表、取消与重试；接收手机可以切换应用，来源端仍需保持玉响运行。
- 图片双指/双击缩放、下滑返回及转场动画；下载后读取经过尺寸限制的本机图片预览，视频使用系统兼容应用打开，文件可通过系统分享面板发送。

完整变更见 [CHANGELOG](../../CHANGELOG.md)。

## 安装前须知

**安装过调试版的设备，需要先卸载调试版。** 两者证书不同，无法直接覆盖安装。卸载会清除玉响的设置、目录授权、离线缓存、下载记录和未完成分片；原始共享照片与已存到外部接收目录的文件会保留。重新安装后需再次授权目录和发现设备。

1. 将通用 APK 传到两台 Android 16+ 手机并安装；按系统提示允许对应文件管理器或浏览器安装应用。
2. 两台手机连接同一 Wi-Fi，打开玉响，分别选择共享目录与接收目录。
3. 等待发现设备；没有自动发现时，输入另一台手机显示的 `IP:端口`，或扫描它的连接二维码。
4. 点击照片或视频下载，允许通知权限。接收端可退到后台，来源端保持玉响打开。
5. 完成后检查接收目录、预览和系统分享。之后新增或删除媒体，可通过刷新更新目录。

需要命令行安装、校验或后续升级时，参阅 [发布与打包](../发布.md)。密钥、密码和签名配置不随 APK 分发。

## 已知限制与待验收

- 仅支持 Android 16+ 和私有 IPv4 局域网；不支持 Android 15 及以前版本、IPv6、互联网中转、账号、鉴权或 TLS。请在自己的可信局域网使用。
- 来源端未实现常驻共享服务，需要保持玉响打开；后台接收受系统网络与资源约束。被系统任务管理器停止或强行停止应用后，需回到应用重试。
- 目录不是实时同步。本机扫描仍需遍历完整轻量元数据，超大目录耗时受文档提供者影响。
- 仅同步增删，不处理内容编辑或跨设备内容去重；下载不会自动删除共享目录或其他设备上的原照片。
- 未完成分片会占用应用存储。外部目录保存成功后、数据库登记前若进程被强杀，可能留下完整但未登记的副本，重试可能另存一个文件。
- 媒体预览能力由 Android 解码器与系统可用应用决定；格式不受支持时可尝试下载并交给其他应用打开。
- 两台真机上的自动发现、扫码、SAF 授权与成功落盘、系统分享、断网恢复、锁屏及厂商省电策略仍需验收。完整检查清单位于 [Android 原型](../Android原型.md)。
