## 本版新增与改进

- 设置中可添加和独立移除多个共享目录；每个目录递归扫描图片与视频。拒绝重复选择，以及先选父目录再选子目录、先选子目录再选父目录的重叠选择，拒绝后保留原有列表。
- 接收文件按「设备名 / 共享目录名 / 原有子目录 / 文件名」保存，保留来源目录层级。不同设备、不同共享根及子目录产生同名时分别分配目录；文件同名时另存，避免覆盖已有文档。
- 相册首页按对端共享目录显示合集，展示设备、封面和媒体总数；进入合集后平铺浏览其所有子目录的媒体，支持分页、设备筛选和离线缓存。不同设备或不同共享根的同名合集保持独立。
- 下载任务保存来源目录和目标目录映射，后台任务重启与重试继续使用相同位置；目录权限撤销、创建失败或空间不足时保留已接收分片供重试。
- 任一共享目录扫描失败时不发布不完整快照，对端保留上次完整缓存；移除失效共享目录后可恢复其余共享，移除目录不会删除原文件或已下载副本。

局域网自动发现、输入 IP、扫码连接、点击下载、大于 50 MiB 四路下载、后台通知、分片续传、预览和系统分享等原有功能继续保留。完整改动见 [CHANGELOG](../../CHANGELOG.md)，实现与验收细节见 [多目录共享与合集](../多目录共享与合集.md)。

## 安装与升级

**两台设备都需要更新到 0.0.2。** 本版使用 gRPC 协议 v3，不提供旧协议适配。媒体库 schema 为 3、下载任务库为 2；旧数据库会清空重建，不保留旧配置、设备缓存或下载记录，需要重新选择共享与接收目录、发现设备。原始共享照片和已保存到外部接收目录的文件保留。

使用 0.0.1 release 版的设备可直接覆盖安装，因为本版沿用相同签名且 versionCode 递增：

```sh
adb install -r dist/0.0.2/Tamayura-0.0.2-android.apk
```

首次安装可以去掉 `-r`，也可以把 APK 传到手机后通过文件管理器安装。若设备装有旧调试版，则需先卸载；debug 与 release 签名不同，无法直接覆盖。卸载会清除设置、目录授权、缓存、下载记录和未完成分片，外部共享与接收文件保留。

1. 两台 Android 16+ 手机安装本版，连接同一 Wi-Fi 并打开玉响。
2. 各自添加一个或多个共享目录，例如 `DCIM` 与 `Pictures`；选中 `DCIM` 后无需再选其中的 `Camera`。设置独立接收目录，避免与共享目录混用。
3. 等待自动发现，或手动输入另一台设备显示的 `IP:端口`、扫描连接二维码。
4. 打开相册合集并点击媒体下载；检查接收目录中的设备目录、共享目录和多层子目录。下载期间来源端保持应用打开，接收端可切换应用。

## 已知限制与待验收

- 仅支持 Android 16+ 和 IPv4 局域网；尚未提供其它平台安装包、账号、鉴权或 TLS。
- 来源端仍需保持玉响打开；系统停止任务或强行停止应用后，需要回到应用重试。锁屏及厂商省电策略仍待真机验收。
- 非实时同步，只同步媒体增删，不处理原文件内容修改或跨设备内容去重；合集不会自动批量下载。
- 目录关系无法可靠确认时拒绝添加，部分文档提供者可能因此无法组合共享。任一共享目录授权失效或扫描失败都会使当次共享快照不可用，需恢复授权或移除失效目录。
- 超大目录的扫描耗时受存储提供者影响；空共享目录不会生成相册合集。
- 未完成分片占用应用存储；外部保存成功后、数据库登记前若进程被强杀，可能留下未登记副本，重试可能另存文件。媒体预览仍受 Android 解码器和系统应用能力限制。
- 真实双机需验证多个共享根、双向父子重叠拒绝、嵌套文件接收、同名设备与同名共享根隔离、并行创建目标目录、授权撤销与恢复、自动发现、扫码、分享及断网恢复。

正式公开发布前还需完成上述真机验收及干净环境重建；发布步骤见 [发布与打包](../发布.md)。
