# 合集快速滚动

Android 与 iOS 进入相册合集后，上下滑动会显示右侧快速滚动块。按住滚动块上下拖动，可以直接跳到整个合集的任意位置，包括尚未加载缩略图的位置。松手且页面停止滚动后保持显示 3 秒，再用 300 毫秒淡出；期间重新滑动或按住滚动块会取消隐藏。合集列表、桌面端和图片不足一屏的合集不显示滚动块。

## 排序提示

- 日期升序或降序：顶部浮层显示当前视口中央图片的本地日期和星期，右侧显示当前年月，并按空间显示其他年月位置标记。日期仍取文件修改时间，与现有排序一致，不代表 EXIF 拍摄时间。
- 名称升序或降序：右侧显示当前文件名首字母，ASCII 小写转为大写 A–Z；数字、标点、中文、空格及其他非 ASCII 字母均显示 `#`。不会跳过开头空格，也不转换拼音。
- 索引遵循当前完整文件名的 SQLite `BINARY` 顺序，不改变排序语义；大小写分段和非字母分段可能重复出现。标记空间不足时减少显示，当前定位标签始终保留。
- 顶部日期按实际网格布局定位：扣除设备筛选、合集名称等前置内容，计算视口中央所在行和中央列；偶数列使用右侧中央图片。行间空隙取较近行，首尾不足时限定到现有图片。

## 实现

`AlbumFastScroll` 包裹移动端合集的 `CustomScrollView`，监听纵向滚动及布局变化，负责拖动、可访问性翻页动作和显隐计时。滑块位置对应整个滚动范围，拖到两端分别到达顶部和底部。日期和位置标记不拦截图片点击，只有滑块接收拖动；隐藏后不占据触摸区域。

位置标记会随滑块位置增减，因此滑块、当前标签和各标记的最外层 `Positioned` 使用稳定 key，保证滑块的手势子树在兄弟节点数量变化时仍被保留。仅给内部 `GestureDetector` 设置 key 无法保护被替换的父节点：旧实现会在拖动中销毁手势识别器，后续移动及松手事件丢失，拖动状态未清除也使隐藏计时无法启动。修复后保留原有停止滚动后 3 秒、300 毫秒淡出的规则。

滑块拖动的输入回调直接更新滚动位置及当前图片索引，让滑块、日期和网格在下一帧同时更新，不再等帧末回调后多绘制一帧。布局变化的校正和缩略图窗口请求仍合并到帧末处理，避免布局过程中同步修改状态或在每个指针事件中重复读取缩略图。

网格在 `SliverLayoutBuilder` 中提供实际列数、行高、间距及前置 sliver 长度给 `AlbumScrollGeometry`。紧凑模式、详细模式、横竖屏与文字缩放共用这一计算，避免写死顶部高度。切换合集或排序会清除浮层状态；离开相册页停止显示，组件销毁时清理计时器和监听。

仓储提供全合集 `MediaScrollEntry` 索引，只读取标识、名称及修改时间，不读取缩略图 BLOB。索引与普通分页使用相同设备、共享目录、排序和同步暂存视图。移动端以完整索引长度建立虚拟网格，未加载的位置显示占位图，进入可见区域后按标识请求缩略图窗口；离线缓存同样可用。普通分页接口继续用于桌面和没有索引的视图。

可见窗口向两侧预取，通常以当前视口为中心请求最多 200 项，避免平板上前置预取挤掉可见图片；超长视口优先保全所有可见行，仓储仍分成每批最多 200 项读取。控制器合并快速拖动中的后续请求，只处理最新位置；额外缩略图缓存通常最多 240 项，超长视口按当前窗口容量保留，避免滑过整个合集后永久保留全部图片。合集、设备、排序或同步更新会使旧请求失效，旧结果和错误不会覆盖新视图。窗口读取失败走现有错误提示，未加载位置可点击重试，滚到其他位置也可继续读取；这些操作不会下载原文件。

移动端多选独立保留已选媒体引用，按完整索引及本地保存状态修剪，避免滚动窗口淘汰缩略图后丢失选择或无法删除已选本地文件。

无需新增依赖、数据库结构或通信协议；交互参考系统相册样式，代码为项目内 Flutter 实现。
